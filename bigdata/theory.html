    변환한 문자열을 bc_card_output.txt에 씁니다.

3헤더 끝(CNT) 뒤에 탭 넣기

  1. data.find('CNT')

    find는 문자열이 처음 나오는 위치(인덱스)를 돌려줍니다. 헤더 마지막 컬럼 CNT의 위치는 257이고, 끝나는 위치가 260입니다. 없으면 -1.

  2. data=data[:260]+'\t'+data[260:]

    슬라이싱으로 260 앞뒤를 자르고 그 사이에 탭을 끼워 넣습니다. 헤더(CNT)와 첫 레코드(201906…)가 붙어 있던 것을 떼어 냄.

  3. split_data=data.split('\t')
split_data[22], split_data[23]

    다시 나누면 22번은 'CNT', 23번은 첫 레코드의 '201906'이 됩니다.

4레코드마다 '201906' 앞에 탭 넣기

  1. Cycle=22
i=1

    첫 레코드부터는 앞 레코드의 CNT와 다음 레코드의 연월이 한 칸에 붙어 있어서 22칸마다 반복됩니다.

  2. while i < round((len(split_data)-Cycle)/Cycle):

    레코드 개수만큼 반복합니다.

  3.   target_index=split_data[No_Column+Cycle*i].find('201906')

    붙어 있는 칸(예: '3201906')에서 연월 201906이 시작하는 위치를 찾습니다.

  4.   split_data[No_Column+Cycle*i]=split_data[No_Column+Cycle*i][:target_index]+'\t'+split_data[No_Column+Cycle*i][target_index:]
  i+=1

    그 위치 앞에 탭을 넣어 CNT 값과 연월을 분리하고 다음 레코드로 넘어갑니다.

def sq_error_grad(xi, yi, theta):
  alpha, beta=theta
  return [-2 *(yi-(beta * xi + alpha)),-2 *(yi-(beta * xi + alpha)) * xi]
def vector_subtract(v, w):
  return [vi - wi for vi, wi in zip(v,w)]
def scalar_multiply(c, v):
  return [c * vi for vi in v]
def sgd1(sq_error, sq_error_grad, x, y, theta_0, l_rate_0):

  return min_theta
