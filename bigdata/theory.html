라이브러리 · 패키지 · 모듈이 뭔가요?

파이썬은 기본 기능만으로는 표 분석이나 머신러닝을 하기 어려워서, 남들이 미리 만들어 둔 코드 묶음을 가져다 씁니다. 이 묶음을 크기 순으로 부르는 이름이 있습니다.

클래스 → 객체 → 메서드 (sklearn 모델 쓰는 법)

클래스(설계도)로 객체(실물)를 만들고, 객체에 점(.)을 찍어 기능(메서드)을 씁니다. 점 뒤에 괄호 없이 값만 꺼내는 것은 속성입니다.

  1. model=DecisionTreeClassifier(criterion='entropy', max_depth=3, min_samples_leaf=5)

    읽기이 설정으로 의사결정나무를 하나 만들어 model이라 부르자.

    클래스이름(설정) = 객체 만들기. 괄호 안은 모델 설정값.

  2. model.fit(X_train, y_train)

    읽기model아, X_train과 y_train으로 학습해라.

    객체.메서드(재료). fit = 학습.

  3. y_pred=model.predict(X_test)

    읽기model아, X_test를 예측해라. 결과는 y_pred에 담자.

    predict = 예측.

  4. SS=StandardScaler()
SS.fit(X)
X_ss=SS.transform(X)

    읽기표준화 도구를 만들어 SS라 하고, X로 기준을 계산한 뒤, X를 변환해 X_ss에 담아라.

    스케일러도 클래스 → 객체 → 메서드 순서.

  5. accuracy_score(y_test, y_pred)

    읽기y_test와 y_pred로 정확도를 계산해라.

    함수는 객체를 만들지 않고 이름(재료)로 바로 씁니다. 점이 없음.

  6. log_reg.coef_

3헤더 끝(CNT) 뒤에 탭 넣기

  1. data.find('CNT')

    읽기data에서 'CNT'가 몇 번째 글자에 있는지 찾아라.

    find는 문자열이 처음 나오는 위치(인덱스)를 돌려줍니다. 헤더 마지막 컬럼 CNT의 위치는 257이고, 끝나는 위치가 260입니다. 없으면 -1.

  2. data=data[:260]+'\t'+data[260:]

    읽기data의 260번 앞까지 + 탭 + 260번부터 끝까지를 이어 붙여 data를 고쳐라.

    슬라이싱으로 260 앞뒤를 자르고 그 사이에 탭을 끼워 넣습니다. 헤더(CNT)와 첫 레코드(201906…)가 붙어 있던 것을 떼어 냄.

  3. split_data=data.split('\t')
split_data[22], split_data[23]

    읽기다시 탭으로 자르고, 22번째와 23번째 값을 확인해라.

    다시 나누면 22번은 'CNT', 23번은 첫 레코드의 '201906'이 됩니다.

  2. while i < round((len(split_data)-Cycle)/Cycle):

    읽기i가 레코드 수보다 작은 동안 반복해라.

  if x=="Special":
    return 1
  else:
    return 0
titanic_df1["special_title"]=titanic_df1["title"].apply(convert_title)
titanic_df1.drop('title', axis=1, inplace=True)

def correlation(x, y):
  stdev_x=standard_deviation(x) # 표준편차(x) 할당
  stdev_y=standard_deviation(y) # 표준편차(y) 할당
  if stdev_x > 0 and stdev_y > 0:
    return covariance(x, y) / (stdev_x * stdev_y) # 상관계수 결과 반환
  else:

import math
def coefficients_sgd(train, l_rate, n_epoch):
  coef=[0.0 for i in range(len(train[0]))] #초기 회귀계수 값
  for epoch in range(n_epoch):
    sum_error=0
    for row in train:
      yhat=predict(row, coef)
      error=row[-1]-yhat
      sum_error+=(error**2)
      coef[0]=coef[0]+l_rate*error
      for i in range(len(row)-1):
        coef[i+1]=coef[i+1]+l_rate*error*row[i]
  return coef, math.sqrt(sum_error/len(train))

# ── 5. 종합 및 심화: 학습률을 줄여 가는 경사하강법 ──
def sq_error(xi, yi, theta):
  alpha, beta=theta
  error=yi-(beta * xi + alpha)
  sq_error=error**2
  return sq_error
def sq_error_grad(xi, yi, theta):
  alpha, beta=theta
  return [-2 *(yi-(beta * xi + alpha)),-2 *(yi-(beta * xi + alpha)) * xi]
def vector_subtract(v, w):
  return [vi - wi for vi, wi in zip(v,w)]
def scalar_multiply(c, v):
  return [c * vi for vi in v]
def sgd1(sq_error, sq_error_grad, x, y, theta_0, l_rate_0):
  data=list(zip(x, y))
  theta=theta_0
  l_rate=l_rate_0
  min_value=float("inf")
  iterations=0
  while iterations < 5:
    value=sum(sq_error(xi, yi, theta) for xi, yi in data)
    if value < min_value:
      min_theta, min_value=theta, value
      iterations=0
      l_rate=l_rate_0
    else:
      iterations+=1
      l_rate*=0.9
    for xi, yi in data:
      gradient_i=sq_error_grad(xi, yi, theta)
      theta=vector_subtract(theta, scalar_multiply(l_rate, gradient_i))
  return min_theta
