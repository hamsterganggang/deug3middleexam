계산 문제 빠른 대비

기울기와 절편

  • 두 점 (x₁, y₁), (x₂, y₂)를 지나는 직선의 기울기 = (y₂ − y₁) ÷ (x₂ − x₁)
  • 예: (1, 4)와 (3, 10) → 기울기 = 6 ÷ 2 = 3 → 4 = 3 × 1 + b → b = 1 → y = 3x + 1

2차함수 최솟값 (두 가지 방법)

  • 꼴이 y = a(x − p)² + q면 바로 읽음: x = p일 때 최솟값 q (a > 0)
    • 예: y = (x − 3)² + 2 → x = 3일 때 최솟값 2
  • 꼴이 y = x² + bx + c면 미분해서 0으로 놓음
    • 예: y = x² − 6x + 10 → 미분 2x − 6 = 0 → x = 3 → y = 9 − 18 + 10 = 1

최소제곱법 계산 순서

  1. x 평균, y 평균 구하기
  2. 각 점마다 (x − x 평균), (y − y 평균) 구하기
  3. 분자 = 두 편차를 곱해서 모두 더하기, 분모 = x 편차를 제곱해서 모두 더하기
  4. a = 분자 ÷ 분모
  5. b = y 평균 − a × x 평균

평균제곱오차 계산 순서

  1. 각 점의 예측값 구하기 (직선에 x 대입)
  2. 오차 = 실제값 − 예측값
  3. 오차를 각각 제곱해서 모두 더하기
  4. 데이터 개수 n으로 나누기

강의 예제 숫자(2.3, 79, MSE 11)는 챕터 4에 계산표가 있으니 손으로 한 번 다시 풀어볼 것. 예상 문제는 문제 메뉴에 있음.

챕터 1. 딥러닝 시작을 위한 준비 운동

이 챕터의 핵심은 두 가지임. AI, 머신러닝, 딥러닝의 포함 관계, 그리고 딥러닝에 필요한 3요소 중 데이터가 가장 중요하다는 점.

1-1. 인공지능, 머신러닝, 딥러닝의 관계

  • 세 용어를 혼동해서 쓰는 경우가 많은데, 범위로 따지면 인공지능 ⊃ 머신러닝 ⊃ 딥러닝
  • 인공지능이 가장 큰 범주, 그 안에 기계가 학습하는 머신러닝, 머신러닝 중 가장 효율적이고 고도화된 것이 딥러닝
  • 교재의 비유: 인공지능이 "먹을 수 있는 모든 음식"이라면 머신러닝은 "영양가 많은 고기 음식", 딥러닝은 그중 "최고급 스테이크"
  • 강사의 구분법: 머신러닝은 데이터를 어떻게 사용할지 정하는 데 사람의 수작업이 들어감. 그 수작업까지 학습된 규칙으로 컴퓨터가 하게 되면 딥러닝이라고 부름

시험에서 포함 관계를 물으면 이 그림 순서(큰 것부터 AI → 머신러닝 → 딥러닝)대로 답하면 됨.

챕터 2. 미지를 예측하는 원리와 첫 딥러닝 코드

이 챕터의 핵심은 두 가지임. 머신러닝은 데이터와 답 사이의 규칙을 찾아 새 데이터의 답을 예측한다는 원리, 그리고 모든 딥러닝 코드가 따르는 4단계 구조(환경 준비 → 데이터 준비 → 구조 결정 → 모델 실행).

2-1. 미지를 예측하는 원리

기존 프로그래밍 vs 머신러닝

입력출력초점
기존 프로그래밍데이터 + 소스 코드(규칙)답데이터를 넣어 답을 구하는 것
머신러닝데이터 + 답규칙데이터와 답 사이의 규칙을 발견하는 것
  • 기존 환자 데이터로 새 환자를 예측하는 프로그램은 기존 프로그래밍 기법으로 만들기 쉽지 않음. 머신러닝은 이걸 매우 쉽게 해결함
  • 머신러닝은 데이터와 답을 같이 주고(지도학습) 거기서 규칙을 찾아냄. 새로운 데이터가 들어와도 이 규칙으로 답을 알 수 있음

핵심 차이: 기존에는 사람이 규칙을 짠는데, 머신러닝은 데이터와 답에서 규칙을 스스로 찾아냄.

예시: 중환자 수술 의사의 질문

  • 중환자를 전문으로 수술하는 병원 의사가 "수술 후 생존을 미리 예측할 수 없을까?"라고 질문함
  • 자신이 집도한 수술 환자들의 수술 전 상태 = 데이터, 수술 후 생존 여부 = 답(결과)
  • 이 데이터를 머신러닝 알고리즘에 넣으면 패턴과 규칙을 분석해서 저장함
  • 새 환자 데이터가 들어오면 이 패턴과 규칙으로 답을 예측함. 이게 모델임
  • 데이터가 입력되고 패턴이 분석되는 과정 = 학습

학습 과정 (좌표평면으로 보기)

  1. 깨끗한 좌표평면에 기존 환자들을 하나씩 배치
  2. 환자 분포를 보고 수술 성공과 실패를 구분하는 **경계선(직선)**을 그음
  3. 새 환자 데이터를 좌표평면에 찍어서 경계선의 어느 쪽인지로 성공/실패를 예측
  • 우리가 배우는 것은 이런 학습과 예측의 구체적인 과정임
  • 핵심 문제: 이 직선을 어느 한쪽에 치우치지 않게 어떻게 그을 것인가
  • 이걸 위한 노력의 결과로 퍼셉트론, 아달라인, 선형회귀 같은 알고리즘이 개발됐고, 이를 토대로 딥러닝이 탄생함

2-2. 딥러닝 코드의 4단계

  1. 환경 준비: 필요한 라이브러리(모듈) 불러오기
  2. 데이터 준비: 데이터를 불러오고 입력(X)과 결과(y)로 나누기. 공공데이터 활용, 전처리를 여기서 많이 함
  3. 구조 결정: 모델의 층(layer)을 어떻게 쌓을지 정하기. 가장 핵심
  4. 모델 실행: 컴파일하고 학습(fit)시키기

2-3. 환경 준비

  • 텐서플로는 모듈이 워낙 복잡하고 기능이 다양해서 일반적으로 쓰기 까다로움
  • 그래서 텐서플로 안에 있는 케라스라는 도구로 비교적 쉽게 사용함
  • 교재 비유: 텐서플로 = 전투기, 케라스 = 그 전투기를 조종하는 조종사
  • 이 예제는 텐서플로 모듈 2개(Sequential, Dense)와 넘파이 1개, 총 3개 모듈을 씀
  • 뒤로 갈수록 그래프용 matplotlib, seaborn 등이 점점 추가됨
from tensorflow.keras.models import Sequential   # 케라스 API의 models에서 Sequential 사용
from tensorflow.keras.layers import Dense        # 층을 만드는 Dense
import numpy as np                               # numpy를 np로 줄여 부름
  • from A import B: A라는 라이브러리에서 B라는 함수(클래스)를 쓰겠다
  • import A as B: 이름이 길어서 일일이 치기 힘드니 B로 줄여 부르겠다
  • 라이브러리명과 함수명은 정확하게 입력해야 함

2-4. 데이터 준비

  • 데이터는 보통 로컬(하드디스크)의 CSV를 가져오거나, 이번처럼 저자 깃허브에서 다운로드해서 CSV로 사용함
  • 파일: data 폴더 아래 ThoraricSurgery3.csv (폐암 수술 환자 데이터)

데이터 구조

항목내용
행한 줄 = 환자 한 명. 약 470명 (파일상 469행, 0부터 세고 한 명이 빠진 듯)
인덱스 0~15속성 16개 = 입력 데이터. 종양 유형 등 수술 전 환자 정보 (키, 몸무게 같은 종류)
인덱스 16클래스 = 결과(정답). 수술 1년 후 생존 1, 사망 0
한 줄의 숫자속성 16개 + 클래스 1개 = 총 17개
  • 공공데이터에는 보통 각 인덱스(컬럼)가 무엇인지 설명이 달려 있음 (예: 0번은 나이, 몇 번은 심장 박동 관련). 값만 보면 2.88, 2.16처럼 뭔지 모르니 설명을 참고할 것
  • 새 환자(471번째) 데이터 16개가 들어오면 1인지 0인지 판단하는 모델을 만드는 게 목표
  • 환자 샘플 수가 많을수록 데이터 신뢰도와 모델 정확도가 같이 올라감

X와 y로 나누기

X = Data_set[:, 0:16]   # 대문자 X = 입력 데이터 (속성 16개)
y = Data_set[:, 16]     # 소문자 y = 결과 (클래스)
  • 관례: 입력은 대문자 X, 결과는 소문자 y. 앞으로 계속 이 형태로 나옴
  • [행, 열] 형태. 콤마 앞이 행, 뒤가 열
  • 콜론(:)만 있으면 전체. 0:16은 0부터 16 − 1, 즉 0~15까지 (프로그램은 0부터 셈)
  • [:, 16]은 마지막 16번 열만 가져오라는 뜻
  • 2차원 데이터를 다루므로 파이썬의 범위(range, 슬라이싱) 개념을 참고할 것

전처리 (불필요한 데이터 제거)

  • 데이터가 가장 중요한데, 첫째 방대한 양, 그다음 불필요한 데이터는 삭제할 수도 있음. 이걸 전처리로 가공해 나감
  • 예: 폐암 수술 환자 데이터에 성별이 있다고 치자. 폐암 생존에 성별이 크게 상관없다고 판단되면 굳이 넣지 않아도 됨 (억지 예시라고 강사가 언급)
  • 이유: 데이터(속성)가 많아질수록 학습 속도가 떨어짐
  • 비유: 시험 범위가 아닌 과목을 굳이 공부하지 않는 것과 같음

2-5. 구조 결정

model = Sequential()
model.add(Dense(30, input_dim=16, activation='relu'))
model.add(Dense(1, activation='sigmoid'))
  • Sequential(): "이제 구조(모델)를 만들겠다"는 선언. 케라스 안에 있는 기능
  • 모델은 여러 **층(layer)**으로 이루어짐. 층은 일종의 필터라고 생각하면 됨. 필터를 여러 개 겹쳐 설정할 수 있음
  • Dense 하나 = 층 하나
  • input_dim=16: 입력 X의 16개 값을 1번 층에 전달한다는 뜻
  • 마지막에 결과 1개로 내보냄

층의 이름

층설명
입력층데이터가 처음 들어오는 시작 부분
은닉층입력층과 출력층 사이의 층들
출력층최종 결과를 내보내는 부분

Dense를 두 번 썼으니 층이 2개(은닉층 1개 + 출력층 1개)이고, 입력층은 input_dim으로 정해짐.

  • 이 예제는 Dense를 두 번 써서 층이 2개. 층을 겹겹이 쌓아 나가는 게 딥러닝 구조
  • 은닉층이 두꺼울수록 좋을 수도 있지만 나쁠 수도 있음
    • 비유: 휴지 한 장은 물에 금방 젖어서 뚫림. 그런데 수십, 수백, 수천 겹을 쌓으면 위에서 부은 물이 맨 밑까지 안 내려옴
    • 즉 출력이 안 나올 수 있음 = 학습이 제대로 안 될 수 있음
  • 좋은 딥러닝을 만들려면 몇 개 층이 좋은지, 각 숫자와 설정이 무슨 의미인지는 이후에 점진적으로 다룸

2-6. 모델 실행

model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
history = model.fit(X, y, epochs=5, batch_size=16)

compile: 구조를 최적화

설정의미
loss손실 함수(오차 함수). 오차를 보정하기 위한 도구. 여기선 binary_crossentropy
optimizer최적화 함수. 여기선 adam
metrics평가 기준. 보통 accuracy(정확도)라 신경 쓸 필요 없음
  • loss와 optimizer는 뒤 챕터에서 다시 설명함

fit: 실제 학습

  • 몸에 옷을 맞추듯(피팅), 컴파일된 모델 구조를 토대로 실제 학습이 일어나는 단계
  • epochs = 반복 횟수
    • 비유: 500페이지짜리 책을 몇 번 볼 거냐. epochs=5면 책을 5번 정독
  • batch_size = 한 번에 공부하는 양
    • 비유: 500페이지를 16페이지씩 끊어서 공부
  • 즉 "책을 5번 정독하되, 16페이지씩 공부한다"는 개념
  • 이 두 값을 조정하면 정확도가 달라짐. 책을 10번 정독한 사람과 5번 정독한 사람은 차이가 날 수밖에 없음

2-7. 실행 결과와 가중치

  • 정확도 약 0.85 = 약 85%. 자체 검증 결과임
  • 명확한 신뢰도라기보다 "주어진 데이터로 컴퓨터가 시험을 쳐보니 85점 정도 나오더라"는 의미
  • 100명 중 15명은 오진할 수 있다는 뜻
  • 이 정확도 계산 방식에도 문제점이 있음. 어떤 문제가 있고 어떻게 해결하는지는 수업을 진행하며 설명할 예정

실행할 때마다 결과가 미세하게 다른 이유

  • 딥러닝은 처음 가중치를 랜덤하게 정하고, 실행을 반복하면서 가중치를 조금씩 수정해감. 결과는 비슷한 값으로 수렴하지만 미세하게 달라짐
  • 가중치 = 일종의 성향, 취향
  • 비유: 음식을 만들어 처음 먹어보니 싱거우면 소금을 더 치고, 짜면 물을 넣으며 간을 맞춰감. 이 과정을 무수히 반복하는 게 딥러닝의 학습 방법
  • 앞의 경계선으로 보면: 직선의 기울기를 이쪽저쪽으로 바꿔가며 그어보면서, 어느 한쪽에 치우치지 않고 가장 균등하게 나누는 직선을 찾아가는 것

챕터 3. 딥러닝을 위한 기초 수학

이 챕터에서 꼭 깊이 알아야 할 건 세 개뿐임: 1차함수(y = ax + b), 2차함수(최솟값 = 오차 최소), 시그모이드 함수. 편미분 등 나머지는 "이런 함수들로 딥러닝이 설계됐구나" 정도만 이해하면 된다고 강사가 직접 말함.

3-1. 1차함수, 기울기, 절편

  • 함수: 두 집합 사이의 관계를 설명하는 수학 개념. 변수 x와 y가 있을 때 x가 변하면 y가 어떤 규칙으로 변하는지 나타내며 y = f(x)로 씀
  • 1차함수: y가 x에 대한 1차식으로 표현된 것
{% raw %}y=ax+b(a=0){% endraw %}
  • a = 기울기: 기울어진 정도. x가 증가할 때 y가 얼마나 증가하는지로 정해짐
    • 기울기 = y의 증가량 ÷ x의 증가량 (Δy / Δx)
    • 기울기가 3이면 x가 1 증가할 때 y는 3 증가 (음수면 감소)
    • 변화량의 정도를 나타내는 것
  • b = 절편: 그래프가 y축과 만나는 지점

예시

  • 직선 위 두 점에서 x가 1 증가할 때 y도 1 증가 → 기울기 a = 1
  • 그 직선이 y축과 3에서 만남 → 절편 b = 3
  • 직선의 방정식: y = x + 3 (x = 1이면 4, x = 2이면 5)

딥러닝과의 연결 (중요)

  • 딥러닝 수학 원리에서 초반부터 이 식이 등장함
  • x가 주어지고 원하는 y가 있을 때, 적절한 a와 b를 찾는 것. 이게 딥러닝을 설명하는 가장 간단한 표현
  • 예: 앞 장의 폐암 환자처럼 데이터를 좌표에 점으로 찍으면 생존 무리와 사망 무리가 생김. 두 무리 사이를 가로지르는 직선이 이쪽도 저쪽도 아닌 적절한 위치에 오도록 하는 a(기울기)와 b(위치)를 찾는 게 컴퓨터가 딥러닝을 하는 가장 기본 원리

3-2. 2차함수와 최솟값

{% raw %}y=ax2{% endraw %}
  • 그래프는 포물선 (곡선). a > 0이면 아래로 볼록하고 좌우 대칭
  • y = ax²를 x축 방향으로 p, y축 방향으로 q만큼 이동하면:
{% raw %}y=a(x−p)2+q{% endraw %}
  • p와 q는 ax + b의 b처럼 포물선의 위치를 정함. p는 좌우(x 방향), q는 위아래(y 방향)
  • 가장 중요한 건 맨 아래 꼭짓점 = 최솟값
  • 왜 중요한가: 직선을 그었을 때(모델을 설계했을 때) 그게 잘된 건지 판단하는 **기준(오차)**이 필요한데, 그때 이 2차함수가 쓰임. 최솟값 지점이 좋은 모델인지 판단하는 기준이 됨
  • 최솟값은 최소제곱법 공식으로 쉽게 구할 수 있음. 최소제곱법은 최솟값을 찾는 여러 방법 중 하나
  • 그런데 최소제곱법 계산에 필요한 조건을 알 수 없는 경우가 많음 → 그래서 미분과 기울기로 최솟값을 찾아가는 방식을 씀 (뒤 챕터에서 점진적으로 설명)

3-3. 미분: 순간변화율과 기울기 (가장 중요)

왜 미분이 가장 중요한가 (논리 흐름)

  1. 딥러닝은 결국 1차함수의 기울기 a와 절편 b를 구하는 것
  2. a와 b는 2차함수(포물선)의 최솟값을 구하는 것으로 찾음
  3. 그 최솟값을 미분으로 구함

순간변화율 개념

  • y = x² 그래프에서 x축의 한 점 a에 대응하는 y값은 a²
  • a를 오른쪽이나 왼쪽으로 0에 가까울 만큼 아주 미세하게 움직이면, y값도 아주 미세하게 변함
  • 너무 미세해서 실제로 움직인다기보다 "왼쪽 또는 오른쪽으로 간다"는 방향만 있는 순간적인 변화가 됨. 이게 순간변화율
  • 순간변화율은 방향을 가지므로, 그 방향으로 직선을 길게 그리면 그래프에 맞닿는 접선이 됨
  • 접선은 점마다 하나씩 그어지고, 각각 하나의 1차 방정식(ax + b)이 됨
  • 이 접선의 기울기 = 그 점에서의 순간변화율

미분이란

  • 미분 = 순간변화율, 즉 기울기를 구하는 것
  • 어느 순간 어떤 변화가 일어나는지 숫자로 나타낸 것 = 미분계수 = 기울기
  • 기울기가 중요한 이유: 기울기가 0이 되는 지점 = x축과 평행한 직선이 되는 지점 = 포물선의 꼭짓점(최솟값)

점선이 각 점의 접선이고, 그 기울기가 미분값임. 꼭짓점에서만 접선이 x축과 평행(기울기 0)함.

평균변화율 → 순간변화율 공식

  • 두 점 A(a, f(a)), B(b, f(b))를 이은 직선의 기울기 = 평균변화율
  • Δ(델타)는 변화량(차이)을 뜻하는 기호
{% raw %}ΔxΔy​=b−af(b)−f(a)​=Δxf(a+Δx)−f(a)​{% endraw %}
  • 미분에 필요한 건 순간변화율. x의 증가량 Δx를 0에 한없이 가깝게 보낸 값(극한, lim)
{% raw %}Δx→0lim​Δxf(a+Δx)−f(a)​{% endraw %}
  • 함수 f(x)를 x에 대해 미분하라는 표현:

3-4. 편미분

  • 미분과 편미분 모두 "미분하라"는 의미는 같음
  • 차이: 식 안에 변수가 여러 개(x, y 등)일 때, 모든 변수를 미분하는 게 아니라 원하는 한 가지 변수만 미분하고 나머지는 상수로 취급함
  • 수학 전공이 아니면 접할 일이 거의 없음

예시

{% raw %}f(x,y)=x2+yx+a(a는 상수){% endraw %}
  • x에 대해 편미분: y는 상수와 다를 바 없음 → 상수 a는 소거, x²의 지수가 내려와 2x, yx는 y → 결과 2x + y
  • y에 대해 편미분: 이번엔 x가 상수 취급 → x²와 a는 소거, yx는 x → 결과 x
  • 핵심: 어느 변수를 기준으로 미분할 것이냐가 편미분의 기본 개념
  • 당장은 몰라도 괜찮다고 함 (뒤 챕터 경사하강법에서 a와 b로 각각 편미분할 때 쓰임)

3-5. 시그모이드 함수 (중요)

  • 딥러닝 내부를 보면 입력받은 신호를 얼마나 출력할지 계산하는 과정이 무수히 반복됨
  • 입력이 여러 층을 거칠 때, 얼마나 내보낼지를 계산하는 함수 = 활성화 함수(activation function)
  • 시그모이드 함수는 활성화 함수의 한 종류이고, 활성화 함수 중 가장 먼저 배우는 함수
  • 활성화 함수는 딥러닝 발전에 따라 여러 형태로 개발돼 왔음

정의

  • 밑이 자연상수 e인 지수함수를 이용함
  • e = 자연로그의 밑, 오일러 수라고 부름. 약 2.718
  • 이 지수함수가 분모에 들어가면 시그모이드 함수가 됨:
{% raw %}f(x)=1+e−x1​{% endraw %}

(영상에서 강사가 자연상수를 잘못 말한 부분이 있다고 스스로 정정함. 자연상수는 e임)

형태와 특징

  • 그래프가 S자 형태
  • x가 큰 값이면 f(x)는 1에 가까워지고, 작은 값이면 0에 가까워짐
  • 그래서 0 또는 1 둘 중 하나를 고를 때 유용함: "이게 강아지냐 아니냐", "이게 옷이냐 아니냐" 같은 예/아니오 판단
  • 주어진 값(a, b)에 따라 형태가 조금 변하기도 함 (6장에서 자세히)

3-6. 정리

  • 1차함수, 2차함수, 미분, 편미분, 지수함수, 시그모이드, 로그함수를 대략 알면 뒷장의 딥러닝 원리와 이유를 이해하기 좋음
  • 시그마(Σ)는 합을 뜻함
  • 행렬, 체인룰(연쇄법칙)이 등장하는 어려운 계산은 교재 심화편에서 다루는데, 지금은 알 필요 없음
  • 꼭 깊이 알아둘 것
    • 1차함수 ax + b
    • 2차함수 (결국 오차와 기울기를 다루는 데 쓰임)
    • 시그모이드 함수
  • 편미분은 "할 줄 알아?" "아니요"여도 지금 당장은 상관없음

챕터 4. 가장 훌륭한 예측선: 선형회귀, 최소제곱법, 평균제곱오차

이 챕터의 결론: 공부 시간과 성적 데이터로 최소제곱법을 쓰면 가장 좋은 직선 y = 2.3x + 79가 나오지만, 변수가 많아지면 이 공식을 못 씀. 그래서 아무 선이나 긋고 평균제곱오차(MSE)로 평가하며 고쳐나가는 방식이 딥러닝의 핵심 원리가 됨.

4-1. 개요

  • 이 챕터에서 다루는 것: 선형회귀(여러 정보로 결과를 예측), 최소제곱법과 평균제곱오차(내가 만든 예측 방식이 제대로 됐는지 검증하는 방법)
  • 딥러닝은 자그마한 통계 결과들이 무수히 얽혀 이루어지는 복잡한 연산의 결정체임
  • 우리 몸을 알려면 세포를 알아야 하듯, 딥러닝을 알려면 기본 원리 두 가지를 알아야 함: 선형회귀와 로지스틱 회귀
  • 회귀 = 예측하다로 생각할 것 (과거로 돌아간다는 뜻 아님)
  • 이 둘을 중고등학교 수준에서 공부하긴 쉽지 않지만, 우리가 아는 y = ax + b(1차 방정식)로 시작할 수 있음
  • 직선을 어떻게 긋느냐에 따라 O와 X를 분류할 수 있고, 다음에 들어오는 좌표가 O인지 X인지 예측할 수 있음. 즉 미래를 예측하는 게 가능함
  • "가장 훌륭한 예측선"은 선형회귀를 이용하는 방식을 말함. 머신러닝은 제대로 된 선을 긋는 작업부터 시작하고, 선의 방향을 잘 정하면 미래를 예측할 수 있음

4-2. 선형회귀의 정의

  • 문장 1: "학생들의 중간고사 성적이 다 다르다" → 너무 제한적. 학생마다 성적이 다르다는 당연한 사실 외에 알 수 있는 게 없음
  • 문장 2: "학생들의 중간고사 성적이 [ ]에 따라 다 다르다" → 괄호에 시험 성적을 좌우할 만한 것이 들어가면 더 많은 사실을 전달함
    • 예: 공부한 시간, 시험 당일 컨디션, 사교육비 지출액 등
    • 무엇이 들어가든 성적의 이유를 나름 타당하게 설명할 수 있고, 성적 차이와 이유를 나타내는 데 문장 1보다 효과적임

4-5. 파이썬으로 최소제곱법 확인

  • 사람이 일일이 수작업할 수 없으니, 이론을 코드로 만들어 값만 넣으면 a와 b가 나오게 함
import numpy as np

x = np.array([2, 4, 6, 8])       # 공부한 시간
y = np.array([81, 93, 91, 97])   # 성적

mx = np.mean(x)   # x 평균 = 5
my = np.mean(y)   # y 평균 = 90.5

# 기울기 공식의 분모: x 편차 제곱의 합
divisor = sum([(i - mx)**2 for i in x])

# 기울기 공식의 분자: x 편차 × y 편차의 합
def top(x, mx, y, my):
    d = 0
    for i in range(len(x)):
        d += (x[i] - mx) * (y[i] - my)
    return d
dividend = top(x, mx, y, my)

a = dividend / divisor   # 2.3
b = my - (mx * a)        # 79.0
  • 넘파이를 쓰는 이유: 일반 파이썬 리스트(대괄호로 감싸고 쉼표로 구분)는 원소끼리 계산이 안 돼서 코드가 복잡해짐. 넘파이 배열로 바꾸면 행렬 계산이 가능함. 예를 들어 x + y를 하면 알아서 원소별로 더해줌. 수학 계산을 편하게 하려고 만든 모듈
  • **2는 파이썬에서 제곱
  • 분모 계산은 x값을 하나씩 넣어 평균을 빼고 제곱하는 걸 4번 반복하는 것 (편차 계산)
  • 결과: 기울기 2.3, 절편 79로 수작업 결과와 동일함

4-6. 평균제곱오차 (MSE)

최소제곱법의 한계

  • 최소제곱법으로 a와 b를 편하게 구했지만, 이 공식만으로는 모든 상황을 해결하기 어려움
  • 이유: 입력이 여러 개면 처리하기 무리. 지금은 변수가 공부 시간 하나뿐이지만, 맨 처음 폐암 환자 예제는 독립변수 x가 16개, y가 1개인 다중 선형회귀라서 이 공식이 적합하지 않음

대안: 일단 긋고 조금씩 수정하기

  • 가장 많이 쓰는 방법: 일단 선을 긋고, 오차가 크면 줄이는 방향으로, 너무 늘어나면 다시 반대로 위아래 조정해 나감
  • 가설을 하나 세운 뒤 → 주어진 요건을 충족하는지 판단 → 조금씩 변화를 줌 → 변화가 긍정적이면 오차가 최소가 될 때까지 계속 반복
  • 이것이 딥러닝을 가능하게 하는 가장 중요한 원리
  • 딥러닝도 입력단부터 출력까지 왔다 갔다 하면서(티키타카) 오차를 계속 줄여나가서 가장 최적의 결과를 냄

필요한 두 가지 (중요)

  1. 나중에 그린 선이 먼저 그린 선보다 좋은지 나쁜지 판단하는 방법 = 각 선의 오차를 계산하는 방법
  2. 오차가 작은 쪽으로 선을 바꾸는 알고리즘
  • 이게 나중에 코드의 compile 단계에서 loss와 optimizer로 들어감
  • loss = 오차 함수, 즉 오차를 어떻게 보정해 나갈지를 다루는 부분
  • **평균제곱오차(Mean Squared Error, MSE)**도 손실 함수(오차 함수) 중 하나이고, 오차를 구할 때 가장 많이 쓰는 방법

공식

{% raw %}MSE=n1​i=1∑n​(yi​−y^​i​)2{% endraw %}
  • yᵢ = 실제값, ŷᵢ = 예측값, n = 데이터 개수
  • 오차를 제곱해서 모두 더한 뒤 개수로 나눔

계산 예시: 최소제곱법을 안 쓰고 아무 값이나 넣어보기

  • 대충 a = 3, b = 76으로 직선 y = 3x + 76을 그음
  • 이 임의의 직선과 실제 점들 사이 거리(오차)를 잼. 거리 합이 작을수록 잘 그은 직선, 클수록 잘못 그은 직선

오차를 제곱하는 건 정사각형 넓이를 구하는 것과 같음. 큰 오차(5)는 제곱하면 25로 훨씬 크게 반영됨.

  • 오차 제곱의 합 = 1 + 25 + 9 + 9 = 44
  • MSE = 44 ÷ 4 = 11
  • 즉 처음 그은 직선은 평균제곱오차 11을 갖는 직선
  • 이제 a와 b를 조금씩 수정해보면서 11보다 낮아지는지 커지는지 보고 찾아감
  • 수학 공식을 일일이 계산할 필요는 없고 개념만 받아들이면 됨

기울기와 오차의 관계

  • 기울기 a를 너무 크게 잡으면 오차가 커짐
  • 반대로 너무 작게 잡아도 오차가 커짐
  • 기울기가 잘못될수록 실제값과의 거리(오차) 합이 커짐. 기울기가 무한대로 커지면 오차도 무한대로 커짐 (5장의 경사하강법으로 이어짐)

4-7. 파이썬으로 MSE 확인

fake_a_b = [3, 76]   # 임의의 기울기와 절편

def predict(x):
    return fake_a_b[0] * x + fake_a_b[1]

def mse(y, y_hat):
    return ((y - y_hat) ** 2).mean()

predict_result = [predict(i) for i in x]   # 주어진 데이터를 반복하며 예측
print(mse(y, np.array(predict_result)))    # 11.0
  • 결과: 평균제곱오차 약 11
  • 처음 가정한 기울기 3, 절편 76의 오차는 11. 남은 일은 이 오차를 줄이면서 새 선을 그어나가는 것 → 다음 챕터 경사하강법

코드는 영상 설명을 바탕으로 교재 예제 형태로 옮긴 것이라 변수명은 교재 파일과 조금 다를 수 있음.

5-1. 경사하강법이란

  • 4장에서 직선을 긋기 위해 기울기(특히 기울기)를 계속 수정해 나간다고 했음
  • 경사하강법은 처음 기울기 a₁과 두 번째 기울기 a₂ 사이에 어떤 변화를 줄 것인가를 다룸

기울기와 오차의 관계 = 2차함수

  • 기울기 a를 너무 크게 잡아도, 너무 작게 잡아도 오차가 커짐 → 기울기와 오차는 연관(상관관계)이 있음
  • 기울기가 무한대로 커지면 직선이 y축과 거의 나란해지고(세워짐), 무한대로 작아지면 x축과 거의 수평이 됨(눕혀짐). 어느 쪽이든 점들과의 오차도 무한히 커질 수 있음
  • 그래서 기울기 a와 오차 사이에는 2차함수 관계가 있음
    • x축 = 기울기 a, y축 = 오차인 포물선
    • 기울기가 너무 크거나 작은 구간에서는 오차가 계속 커지고, 어떤 특정 기울기에서 오차가 최소가 됨
  • 오차가 가장 작은 지점 = 포물선의 꼭짓점. 이때의 기울기를 m이라고 부름
  • 4장에서 임의의 기울기를 넣고 MSE로 오차를 확인한 것도 결국 이 m을 찾기 위한 것

목표: a₁ → a₂ → a₃ → … → m

  • 처음 임의로 정한 기울기 a₁에서 시작해서 a₂, a₃로 변화해 나가며 최적 기울기 m을 찾아감
  • 그러려면 a₂가 a₁보다 m에 더 가깝고, a₃가 a₂보다 더 가깝다는 것을 컴퓨터가 판단해야 함
  • 이 판단을 가능하게 하는 게 미분, 그리고 그걸 이용한 방법이 경사하강법

5-2. 경사하강법의 원리

  • 3장에서 배운 것: 미분은 한 점에서의 순간 기울기
  • y = x² 같은 포물선 위에는 무수히 많은 점이 있고, 각 점의 순간 기울기를 알려면 그 점에서 미분해야 함
  • 미분하면 그 점의 접선이 나오고, 그 접선의 기울기를 a₁이라고 함
  • 눈여겨볼 것: 최솟값 m에서의 순간 기울기. 포물선 꼭짓점의 접선은 x축과 평행 → 기울기 = 0
  • 즉 미분값이 0이 되는 지점을 찾아가는 것이 우리가 할 일이고, 컴퓨터가 계속 진행해 나가야 할 부분

진행 과정

  1. 처음 기울기 a₁에서 미분해서 접선 기울기를 구함
  2. 그 기울기가 오른쪽 위로 향하면(0보다 크면) 반대 방향으로 이동 → a₂
  3. a₂에서 접선은 오른쪽 아래로 향함(0보다 작음). 부호가 반대가 되도록 왔다 갔다(티키타카) 함
  4. 각 지점에서 기울기를 계속 구하면서 범위를 점점 좁혀감
  5. a₁, a₂, a₃, a₄…를 무수히 거치면 결국 m에 도달
  • 이렇게 경사를 따라 내려가므로 **경사하강법(Gradient Descent)**이라고 부름
  • 정의: 반복적으로 기울기 a를 변화시켜서 m 값을 찾아내는 방법

5-3. 학습률

  • 학습률(learning rate) = a₁에서 a₂, a₃로 이동할 때의 보폭(간격)
  • 앞에서 a₁과 a₂의 부호가 반대가 되게 하라고 했는데, 학습률을 처음부터 너무 크게 잡으면 어떻게 될까?
    • 보폭이 너무 커서 한 점으로 모이지(수렴) 않고 위로 튕겨 올라가버림(발산)
    • 그러면 m 지점을 찾을 수 없게 됨
  • 강사 비유: 학습률 = 공부량. 공부하는 건 좋은데 너무 많이 시키면 퍼져버림
  • 기울기 부호를 바꿔서 이동시킬 때 적절한 거리를 찾지 못해 너무 멀리 이동하면 발산함
  • 그래서 얼마나 이동시킬지 신중히 정해야 하고, 이 이동 거리를 정해주는 게 학습률
  • 딥러닝에서 학습률을 적절히 바꿔가며 최적의 학습률을 찾는 것은 중요한 최적화 과정 중 하나

경사하강법 한 문장 정리

오차의 변화에 따라 2차함수 그래프를 만들고, 적절한 학습률을 설정해서, 미분값이 0인 지점을 구하는 것

절편 b도 마찬가지

  • y절편 b도 같은 성질임. 기울기가 같아도 b가 커지면 직선이 위로, 작아지면 아래로 이동함
  • b가 너무 크거나 작으면 오차가 점점 커짐 → b도 경사하강법으로 찾음

5-4. 파이썬으로 경사하강법 구현

편미분이 필요한 이유

  • MSE 식을 다시 활용함 (식은 굳이 외울 필요 없음)
  • 이 식을 미분할 때 궁금한 건 기울기 a와 절편 b임. 식 전체를 미분하는 게 아니라 필요한 값을 중심으로 미분해야 함
  • 그래서 MSE를 a로 편미분, b로 편미분 함 (3장의 편미분 개념. 용어만 알아도 됨)
{% raw %}∂a∂​MSE=−n2​∑xi​(yi​−y^​i​){% endraw %}
{% raw %}∂b∂​MSE=−n2​∑(yi​−y^​i​){% endraw %}
  • 업데이트 규칙: 기존 값에서 학습률 × 편미분값을 빼서 계속 업데이트
{% raw %}a←a−학습률×∂a∂MSE​,b←b−학습률×∂b∂MSE​{% endraw %}

코드

import numpy as np
import matplotlib.pyplot as plt   # 그래프 모듈

x = np.array([2, 4, 6, 8])       # 공부 시간 (독립변수)
y = np.array([81, 93, 91, 97])   # 성적

a = 0          # 기울기 초기값
b = 0          # 절편 초기값
lr = 0.03      # 학습률
epochs = 2001  # 반복 횟수
n = len(x)

for i in range(epochs):
    y_pred = a * x + b              # 예측값
    error = y - y_pred              # 오차
    a_diff = (2/n) * sum(-x * error)  # a로 편미분한 값
    b_diff = (2/n) * sum(-error)      # b로 편미분한 값
    a = a - lr * a_diff             # 학습률 곱해서 업데이트
    b = b - lr * b_diff
    if i % 100 == 0:                # 100번마다 출력
        print("epoch=%.f, 기울기=%.04f, 절편=%.04f" % (i, a, b))

y_pred = a * x + b
plt.scatter(x, y)
plt.plot(x, y_pred, 'r')
plt.show()

설정값설명

학습률0.03교재 저자가 직접 해보며 찾은 값을 임의로 적용. 최적 학습률은 데이터와 모델마다 달라서 그때그때 찾아야 함

결과

  • 약 1900번째쯤엔 이미 결과값이 같아짐 → 오차가 최소가 되는 최적 지점 도달
  • 그래프로 보면 실제 점들 사이로 y = 2.3x + 79 직선이 그어짐
  • 결론: 최소제곱법을 쓰지 않고도 MSE와 경사하강법으로 오차를 수정해가며 같은 값을 찾을 수 있음
  • 단순 선형회귀뿐 아니라 다중 선형회귀에서도 똑같이 활용 가능. 다만 독립변수가 늘 때마다 업데이트할 값이 늘어나서 코드 길이가 기하급수적으로 늘어남

5-5. 하이퍼파라미터

  • epochs(반복 횟수), 학습률처럼 사용자가 임의로 지정하는 값 = 하이퍼파라미터
  • 강사 비유: "목마르다"고 생각하면 머릿속에서 "물" 또는 "커피"라는 결과가 나옴. 그런데 목마르다는 생각에서 물이라는 결과에 도달하기까지 머릿속에서 어떤 작용이 일어났는지는 다 알 수 없음
  • 딥러닝도 마찬가지로, 내부에서 어떤 과정을 거쳐 그 결과에 도달했는지는 아직 연구 중이고 명확히 밝혀지지 않음 (점점 밝혀지는 중)
  • 그래서 실제로 우리가 조정할 수 있는 파라미터는 많지 않음
  • 지금 코드는 공식을 직접 짰으니 과정을 유추할 수 있지만, 나중에 딥러닝이 데이터를 학습하면 어떻게 공부했고 왜 그런 답을 냈는지까지는 잘 모를 수 있음

5-6. 다중 선형회귀

왜 필요한가

  • 4장의 직선 y = 2.3x + 79는 실제 성적과 약간의 오차가 있었음
    • 4시간 공부한 친구는 88점 예측이었는데 실제로 93점
    • 6시간 공부한 친구는 93점 정도 예측이었는데 실제로 더 낮은 91점
  • 이유: 공부 시간 외의 다른 요소가 성적에 영향을 줬기 때문
  • 더 정확한 예측을 하려면 추가 정보, 즉 독립변수가 있어야 함. 변수 개수를 늘리는 것 = 다중 선형회귀

예제: 과외 수업 횟수 추가

  • 일주일 동안 받은 과외 수업 횟수를 두 번째 독립변수 x₂로 추가
공부 시간 x₁2468
과외 횟수 x₂0423
성적 y81939197

(x₂ 값은 영상에서 다 읽지 않아서 교재 예제 값을 넣었음. 교재와 대조할 것)

  • 이렇게 보니 공부 시간 대비 점수가 아까보다 납득됨. 공부 시간이 비슷해도 2점 정도 차이는 감안할 만한 오차 범위에 들어옴

식이 바뀜

{% raw %}y=a1​x1​+a2​x2​+b{% endraw %}
  • 독립변수마다 각각의 기울기가 추가됨. a₁과 a₂ 모두 경사하강법을 그대로 적용함
  • 코드 변화: 예측식이 바뀌고, 오차 계산은 같고, a₂에 대한 편미분(a2_diff)이 하나 더 생김. 업데이트도 a₂가 추가되고 반복은 동일

차원이 늘어남

  • 공부 시간 x₁, 과외 횟수 x₂, 성적 y → 3차원 좌표에 점이 찍힘. 그래프를 그릴 때 서브플롯(3D)을 추가함
  • 비유: 2차원 면을 자를 땐 선을 그었음. 3차원 큐브를 자를 땐 2차원 **면(평면)**으로 자름
  • 단순 선형회귀 결과는 직선, 다중 선형회귀 결과는 평면
  • 차원이 하나씩 늘수록 계산이 매우 복잡해지고, 더 많은 데이터가 필요함
  • 4차원은 눈으로 본 적은 없지만, 이론적으로 4차원을 자르려면 3차원 공간이 필요함

결과

  • 2000번 반복 후 기울기 a₁ 약 1.5, a₂ 약 2.2 수준으로 나옴
  • 예측 점수와 실제 점수의 차이가 0.3~0.4 수준으로 엄청나게 줄어듦

5-7. 텐서플로로 구현하기

  • 지금까지는 알고리즘을 직접 짰지만, 텐서플로는 머신러닝·딥러닝을 위한 파이썬 모듈로 다양한 모델과 인공신경망 구성 기능을 제공함
  • 텐서플로의 케라스 API로 이런 알고리즘을 쉽게 활용할 수 있음
  • 선형회귀는 현상을 분석하는 방법이고, 이 분석 방법으로 예측 모델을 만드는 게 머신러닝

용어 대응 (중요)

지금까지 배운 것머신러닝·딥러닝 용어
y = ax + b (1차 방정식)가설 함수 H(x)
기울기 a가중치 (weight, w)
절편 b편향 (bias)
평균제곱오차 (실제값과 예측값 차이의 식)손실 함수 (loss function) = 오차 함수
경사하강법옵티마이저 (optimizer)

가중치와 편향 비유 (강사)

  • 가중치 = 선호도. "음식 뭐 좋아해?"라고 물으면 강사는 한식 > 일식 > 양식 > 중식 순으로 좋아함. 사람마다 다를 수 있음
  • 편향 = 그때그때 다를 수 있는 보정. 비가 오면 짬뽕이나 파전에 막걸리가 당김 → 가중치가 가장 낮던 중식이 편향 때문에 1등이 될 수도 있음

compile에서의 위치

  • 코드의 compile 단계에 optimizer=…, loss=…를 적는데, optimizer에 경사하강법, loss에 오차 함수가 들어감
  • 손실 함수도 여러 종류가 있고 지금은 평균제곱오차를 씀. 옵티마이저도 매우 많은데 대표적으로 adam 등이 있음 (뒤에서 설명)

단순 선형회귀 코드

import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

x = np.array([2, 4, 6, 8])
y = np.array([81, 93, 91, 97])

model = Sequential()
model.add(Dense(1, input_dim=1, activation='linear'))  # 층 생성
model.compile(optimizer='sgd', loss='mse')             # 최적화
model.fit(x, y, epochs=2000)                           # 학습 (피팅)

plt.scatter(x, y)
plt.plot(x, model.predict(x), 'r')   # 예측값으로 직선 그리기
plt.show()

hour = 7
prediction = model.predict([hour])
print("%.f시간 공부할 경우 예상 점수는 %.02f점" % (hour, prediction))
  • Sequential과 Dense로 층을 만듦
  • Dense(1, …): 출력되는 성적이 하나라서 첫 인자가 1
  • input_dim=1: 입력 변수도 1개
  • 층이 Dense 하나뿐이고 바로 출력으로 넘어감 → 단층 모델
  • optimizer='sgd' = 경사하강법, loss='mse' = 평균제곱오차
  • 흐름: 층 생성 → 최적화(compile) → 피팅(fit). fit에 들어가야 진짜 학습이 시작됨. "x와 y를 가지고 2000번 피팅해라"
  • predict: 예측값을 구해서 그래프에 그림
  • 결과: 그래프는 직접 짠 코드와 거의 똑같고, 7시간 공부하면 95.12점 예측
  • 직접 알고리즘을 다 친 것보다 코드가 훨씬 짧음
  • 이게 지도학습 중 단순 선형회귀를 이용한 가장 간단한 인공지능 모델

활성화 함수 (activation)

  • 신경망은 생물 시간에 배운 신경처럼, 시냅스 물질이 축삭돌기를 통해 신호를 전달해서 다음 신경으로 넘어가는 체계를 본뜬 것
  • 입력이 들어오면 활성화 함수가 관문 역할을 함. "자극이 충분하면 다음 층으로 넘어가"
  • 비유: 팔을 살살 꼬집으면 안 아프지만, 세게 꼬집으면 아프면서 소리를 지름. 그 기준을 정하는 게 활성화 함수
  • 유명한 활성화 함수로 **ReLU(렐루)**가 있음 (나중에)
  • 지금은 선형회귀라서 linear. 그 외 sigmoid 등 여러 가지가 있음 (6장에서 sigmoid 사용)

다중 선형회귀 코드

x = np.array([[2, 0], [4, 4], [6, 2], [8, 3]])   # [공부 시간, 과외 횟수]
y = np.array([81, 93, 91, 97])

model = Sequential()
model.add(Dense(1, input_dim=2, activation='linear'))   # 입력이 2개
model.compile(optimizer='sgd', loss='mse')
model.fit(x, y, epochs=2000)
  • x가 넘파이 2차원 행렬이 됨. 한 행이 학생 한 명, 각 열이 변수
    • 표로 생각하면: 철수의 [x₁, x₂, x₃, …] 그리고 마지막에 y
    • 괄호(행) 안의 길이 = 독립변수의 수. x₃가 추가되면 콤마로 값이 하나 더 들어감
  • input_dim=2: 입력이 2개로 늘어남. 출력(예상 점수)은 여전히 1개
  • 결과: 2000번 반복 후 오차가 줄어들고, 독립변수 1개 모델보다 2개 모델이 실제 점수에 더 가까운 예측을 함. 즉 정확도가 더 우수함

구조로 보면

  • 단순: 입력 x₁ 하나가 Dense 층으로 들어가서 출력 1개
  • 다중: 입력 x₁, x₂ 두 개가 들어가서 출력 1개 (input_dim이 2)
  • AI는 대표적으로 예측과 분류에 많이 씀
    • 분류 예: 신발 이미지를 넣으면 "신발입니다", 셔츠 이미지를 넣으면 "셔츠입니다"
    • 분류할 종류가 2개면 출력도 2개가 됨 (마지막 Dense의 숫자가 바뀜)

  • 기본적인 머신러닝 코드 구조:

  • epochs 2000이 정답이 아님: 1900번째에 이미 2.3과 79를 구했으니, 시간을 더 쓰는 것보다 1900에서 끊는 게 나을 수 있음. 이런 판단은 직접 해야 함

  • 법정 드라마나 영화에서 검사가 피고인을 다그치는 장면이 종종 나옴
  • 검사의 예리한 질문에 피고인이 당황해서 변명을 늘어놓으면 "예, 아니오로만 대답하세요"라고 함
  • 할 말이 많아도 예 혹은 아니오로만 답해야 할 때가 있음
  • 딥러닝도 마찬가지: 전달받은 정보를 놓고 참과 거짓 중 하나를 판단해서 다음 단계로 넘기는 장치들이 내부에서 쉬지 않고 작동함
  • 딥러닝을 수행한다는 건, 겉으로 드러나지 않는 미니 판단 장치들로 복잡한 연산을 해낸 끝에 최적의 예측값을 내놓는 작업
  • 참/거짓 중 하나를 내놓는 과정이 로지스틱 회귀의 원리를 거쳐 이루어짐

6-2. 왜 직선으로 안 되는가

  • 4~5장에서 공부 시간과 성적의 관계는 좌표에 직선 형태로 찍혔고, 예측선을 직선으로 그었음. 이런 예측에는 선형회귀가 적절했음
  • 그런데 직선으로 해결하기 적절하지 않은 경우가 있음: 결과가 점수가 아니라 합격/불합격일 때
  • 좌표평면에 그려보면, 공부 시간 어느 지점을 기준으로 **왼쪽은 불합격(0), 오른쪽은 합격(1)**으로 나뉨
  • 이 점들을 직선으로 명확하게 표현하기는 힘듦. 1과 0 사이의 값이 없어서 직선으로 그리기 어려움
  • 점들의 특성을 정확히 담으려면 직선이 아니라 S자 형태여야 함

6-3. 시그모이드 함수와 a, b의 의미

  • 로지스틱 회귀도 선형회귀처럼 적절한 선을 그려가는 과정임. 다만 직선이 아니라, 참과 거짓을 구분하는 S자 선으로 분류함
  • 이때 쓰는 게 시그모이드 함수 (3장에서 형태를 봤음)
{% raw %}y=1+e−(ax+b)1​{% endraw %}
  • 여기서도 가운데 ax + b가 중요함. 기울기와 절편의 영향을 받아서 원래 시그모이드 모양이 변함
값의미작을 때클 때
a경사도경사가 완만해짐수직에 가깝게 가팔라짐 (더 타이트하게 구분)
b좌우 이동오른쪽으로 이동왼쪽으로 이동
  • 결국 이번에도 a와 b 두 가지를 찾아가는 과정

a, b와 오차의 관계

  • a 값이 작아지면 오차는 무한대로 커짐
  • a 값이 커지면 오차는 줄어들긴 하지만 0이 되지는 않음
  • b 값이 너무 작거나 너무 크면 오차가 커짐 (선형회귀 때와 같음). 그래프는 2차함수와 비슷한 형태

6-4. 오차 공식: 교차 엔트로피

  • 주어진 과제는 또다시 a와 b 구하기. 시그모이드에서 a, b를 어떻게 구하냐? 답은 경사하강법
  • 복습: 경사하강법은 오차를 구한 뒤 오차가 작은 쪽으로 이동시키는 방법 (티키타카)
  • 이번에도 예측값과 실제값 사이 오차를 구하는 공식이 필요함. 그런데 평균제곱오차를 쓸 수 없음

왜 MSE를 못 쓰나

  • 시그모이드 그래프의 특징: y값이 끝없이 커지거나 작아지는 게 아니라 0과 1 사이
  • 오차가 커지는 경우:
    • 실제값이 1인데 예측값이 0에 가까워지면 오차가 커짐
    • 실제값이 0인데 예측값이 1에 가까워져도 오차가 커짐
  • 이걸 공식으로 만들 수 있게 해주는 함수가 로그 함수

두 개의 로그 그래프 (h = 예측값)

실제값쓰는 그래프특징
1 (파란선)−log h예측값이 1이면 오차 0, 예측값이 0에 가까울수록 오차가 커짐
0 (빨간선)−log(1 − h)예측값이 0이면 오차 0, 예측값이 1에 가까울수록 오차가 커짐

하나로 합친 식

{% raw %}−{ylogh+(1−y)log(1−h)}{% endraw %}
  • 실제값 y가 1이면 뒷부분 (1 − y)가 0이 돼서 사라짐 → 앞부분(−log h)만 남음
  • 실제값 y가 0이면 앞부분 y가 0이 돼서 사라짐 → 뒷부분(−log(1 − h))만 남음
  • 그래서 실제값에 따라 파란 그래프와 빨간 그래프를 각각 쓸 수 있음
  • 이게 평균제곱오차를 대체하는 손실 함수 = 교차 엔트로피(cross entropy)

손실 함수 정리

모델손실 함수
선형회귀평균제곱오차 (MSE)
로지스틱 회귀교차 엔트로피 (cross entropy)
  • MSE는 단순한 모델에서 주로 쓰고, 앞으로 나오는 모델은 대부분 교차 엔트로피 기반
  • 손실 함수는 굉장히 많지만 지금은 이 두 개만 기억하면 됨

6-5. 코드

import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

x = np.array([...])   # 학생 8명의 공부 시간
y = np.array([...])   # 합격 여부 (불합격 0, 합격 1)

model = Sequential()
model.add(Dense(1, input_dim=1, activation='sigmoid'))   # 시그모이드!
model.compile(optimizer='sgd', loss='binary_crossentropy')   # 교차 엔트로피!
model.fit(x, y, epochs=5000)

plt.scatter(x, y)
plt.plot(x, model.predict(x), 'r')
plt.show()

hour = 7
prediction = model.predict([hour])
print("%.f시간 공부할 경우 합격 예상 확률은 %.01f%%" % (hour, prediction * 100))

  • 독립변수에 따라 O/X로 딱 떨어지는 결과를 예측 → 로지스틱 회귀

챕터 7. 퍼셉트론

퍼셉트론은 입력에 가중치를 곱해 더하고(가중합) 바이어스를 더한 뒤, 활성화 함수로 출력을 정하는 신경망의 기본 단위임. 직선 하나로 나누는 것이라 AND·OR은 되지만 XOR은 못 함.

7-1. 퍼셉트론이란

  • 사람의 뇌는 뉴런 약 1천억 개가 촘촘히 연결된 구조. 뉴런과 뉴런 사이의 연결 부위가 시냅스
  • 자극을 받으면 시냅스에서 화학 물질이 나와 전위가 바뀌고, 전위가 임계값을 넘으면 다음 뉴런으로 신호를 전달, 못 넘으면 아무것도 안 함
    • 꼬집기 비유: 세게 꼬집으면 "아" 하고 반응, 살짝이면 모르고 지나감 → 이게 활성화 함수(activation)
  • 이 메커니즘이 앞서 배운 로지스틱 회귀와 많이 닮음: 입력 → 활성화 함수 → 일정 수준을 넘으면 참, 아니면 거짓(예/아니요)
  • 뉴런과 비슷한 구조를 많이 쌓으면 생각하는 무언가를 인공적으로 만들 수 있지 않을까? → 인공신경망(neural network) 연구의 출발. 1943년 논문이 처음 그 가능성을 주장
  • 그걸 실제 장치로 만들어 선보인 것이 퍼셉트론(perceptron) (강의: "이건 당연히 시험에 나옴")
    • 입력값을 여러 개 받아 출력을 만들고, 입력값의 가중치를 조절할 수 있게 해서 최초로 학습을 하게 함
  • 퍼셉트론이 여러 개 모여 복잡한 체계를 이룬 것 = 신경망 (8장 강의 첫 부분)

7-2. 가중합과 활성화 함수 (출제 포인트)

  • 입력값 x₁, x₂, …에 각각 가중치 w를 곱해서 모두 더하고, 바이어스 b를 더함 = 가중합(weighted sum)
{% raw %}가중합=x1​w1​+x2​w2​+⋯+xn​wn​+b{% endraw %}
  • 가중합을 활성화 함수에 넣어 출력(0 또는 1 등)을 정함
    • 가장 단순한 형태: 가중합이 0보다 크면 1, 아니면 0 (계단 함수)
    • 6장의 시그모이드도 활성화 함수 중 하나
  • 앞 챕터와의 연결: y = ax + b에서 a → 가중치 w, b → 바이어스. 독립변수가 두 개인 다중 선형회귀 식과 같은 모양이고, 입력이 100개, 1000개가 돼도 xₙwₙ까지 늘어날 뿐 똑같음
  • 퍼셉트론 → 아달라인 → 로지스틱 회귀 (강의: "이 구조까지만 기억")
    • 가중합으로 선을 그어 보면 오차가 최소인 직선이 여러 개 있을 수 있음
    • 아달라인(Adaline): 퍼셉트론 3년 뒤, 경사하강법을 도입해 그중 가장 적절한 경계선 하나를 고르게 함. 이후 SVM(서포트 벡터 머신) 같은 머신러닝 알고리즘으로 발전
    • 로지스틱 회귀: 여기에 시그모이드를 활성화 함수로 써서 참/거짓을 판단한 것
  • 용어 정리:
용어뜻
가중치 (weight, w)입력이 결과에 미치는 영향의 크기. 기울기 a에 해당
바이어스 (bias, b)보정값. 절편 b에 해당
가중합입력 × 가중치를 모두 더하고 바이어스를 더한 값
활성화 함수가중합을 보고 다음으로 얼마나 내보낼지 정하는 함수 (계단, 시그모이드, ReLU 등)

"합성곱"이라는 말에 대해: 출제 포인트와 8장 강의에서 "합성곱", "합성 곱합"이라고 부르는 건 7장 강의에서 설명한 가중합(입력 × 가중치를 더하고 바이어스를 더함)과 같은 것임. 1장에서 나온 CNN의 "합성곱(convolution)"은 이미지에 필터를 훑는 다른 개념이니 시험에서 헷갈리지 말 것. 퍼셉트론 문제에서 "곱해서 더한다"가 나오면 가중합.

7-3. 퍼셉트론의 과제: XOR 문제

  • 퍼셉트론 하나는 결국 직선 하나로 점들을 나누는 것
  • 논리 게이트로 확인 (입력 x₁, x₂가 0 또는 1):
x₁x₂ANDORNANDXOR
000010
010111
100111
111100
  • AND: 둘 다 1일 때만 1 → 직선 하나로 나눌 수 있음
  • OR: 하나라도 1이면 1 → 직선 하나로 나눌 수 있음
  • NAND: AND의 반대 (둘 다 1일 때만 0)
  • XOR (배타적 논리합): 둘이 서로 다를 때만 1 → 1인 점과 0인 점이 대각선으로 엇갈려 있어서 직선 하나로는 절대 못 나눔
  • 퍼셉트론과 아달라인은 모두 2차원 평면에 직선을 긋는 것만 가능해서, 아무리 그어도 해결되지 않는 상황이 있음
  • 『퍼셉트론즈(Perceptrons)』 논문에서 이 한계가 지적되며 인공지능이 오랫동안 침체됨 → 다층 퍼셉트론과 오차 역전파로 상당 부분 해소 (8장)

XOR은 파란 점(1)이 대각선으로 엇갈려 있어서 선이 두 개 필요함. 이 "선 두 개"가 8장의 은닉층 퍼셉트론 두 개임.

챕터 8. 다층 퍼셉트론

다층 퍼셉트론은 단일 퍼셉트론이 못 푼 XOR 문제를 풀려고 나왔음. 입력층과 출력층 사이에 은닉층을 만들어 퍼셉트론 두 개를 동시에 계산하게 해서 해결함.

8-1. 신경망 복습

  • 퍼셉트론은 인간의 뇌를 모방한 것이고, 이것들이 모여 복잡한 체계를 갖춘 것이 신경망
  • 다층 퍼셉트론이 나온 이유 (출제 포인트): 단일 퍼셉트론으로는 AND, OR은 해결할 수 있었지만 XOR 문제를 해결할 수 없었기 때문에, 여러 개의 퍼셉트론을 이용해 해결하려고 고안됨

8-2. 발상의 전환: 차원을 바꿔 보기

  • 종이 위에 엇갈려 놓인 점들(XOR)은 한 평면에서 선 하나로 완벽하게 분류할 수 없음 → 다른 시각에서 접근이 필요했음
  • 성냥개비 비유: 성냥개비 6개로 정삼각형 4개를 만들 수 있을까?
    • 평면(2차원)에서는 불가능
    • 2차원 평면에서만 풀려는 고정관념을 깨고 3차원으로 보면 피라미드(정사면체) 모양으로 정삼각형 4개를 만들 수 있음
  • 인공지능 학자들도 인공신경망을 개발하려면 반드시 XOR 문제를 풀어야 했음. 고정관념을 버리고 종이를 휘어서(차원을 접어서) 선을 그으면 두 경우를 분리할 수 있었음
  • 종이를 휘어 선 두 개를 동시에 긋는 것 = 퍼셉트론 두 개를 한 번에 계산하면 된다는 결론
  • 그래서 퍼셉트론 두 개를 각각 처리하는 **은닉층(hidden layer)**을 만들게 됨

8-3. XOR을 게이트로 풀기

  • XOR = NAND와 OR를 각각 계산하고, 그 두 결과를 AND로 합침
  • NAND는 AND의 부정: AND는 둘 다 1일 때만 1인데, NAND는 그걸 반전시켜 둘 다 1일 때만 0

  • 피라미드를 쌓듯이 층을 하나 더 올려서 두 연산(NAND, OR)을 동시에 처리하는 것
  • 단일 퍼셉트론은 입력이 출력 하나에 집중되는 형태였는데, 이걸 벗어나 입력 → 은닉층 → 출력층 구조로 만들어 XOR을 해결함

8-4. 다층 퍼셉트론의 설계

  • 단일 퍼셉트론: x₁, x₂가 하나의 연산(노드)에 들어가서 바로 출력
  • 다층 퍼셉트론: 각 입력이 은닉층의 두 노드에 각자 들어감
  • 은닉층 노드 n₁, n₂의 가중합 (각각이 하나의 퍼셉트론 연산):
{% raw %}n1​=x1​w11​+x2​w21​+b1​{% endraw %}
{% raw %}n2​=x1​w12​+x2​w22​+b2​{% endraw %}
  • 각 값에 활성화 함수(시그모이드)를 적용한 결과가 출력층으로 전달되고, 출력층에서 다시 한 번 퍼셉트론 연산이 일어남:

  • 그림의 점선 부분이 은닉층. 은닉층의 중간 정거장을 노드라고 하며 n₁ … nₙ으로 표기, 입력도 x₁ … xₙ
  • 필요한 값: 가중치 6개(w₁₁, w₁₂, w₂₁, w₂₂, w₃₁, w₃₂)와 바이어스 3개(b₁, b₂, b₃). 이걸 2차원 배열로 늘어놓아 표시함

가중치는 기하급수적으로 늘어남 (출제 포인트)

  • 입력과 은닉층 노드가 많아질수록 가중치 w도 기하급수적으로 늘어남
  • 예: 입력 100개, 은닉층 노드 100개면 그 사이에만 최소 1만 개(100 × 100)의 가중치가 생김
  • 은닉층은 하나가 아닐 수 있음. 1번, 2번, 3번, 4번… 점점 두꺼워지고 고도화되면서 복잡한 신경망을 이룸 → 이것이 인공신경망(딥러닝)의 기본 개념
