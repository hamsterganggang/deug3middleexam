1장. 딥러닝 시작을 위한 준비 운동

정리본인공지능과 머신러닝과 딥러닝이 어떤 집합 분류로 되어있는지 · 딥러닝 실행을 위해 필요한 세 가지 [데이터, 컴퓨터, 프로그램]

AI · 머신러닝 · 딥러닝의 포함 관계

  • 인공지능(AI) ⊃ 머신러닝 ⊃ 딥러닝: AI가 가장 큰 범위, 그 안에 머신러닝, 머신러닝의 일부분이 딥러닝
  • 머신러닝 = 데이터로 규칙을 찾아 예측하는 것. 데이터를 어떻게 쓸지는 사람이 수작업으로 정하는 부분이 있음
  • 딥러닝 = 머신러닝의 여러 알고리즘 중 하나로, 가장 좋은 효과를 내는 것. 사람이 하던 수작업 부분까지 기계가 학습으로 처리
  • 음식 비유: AI = 먹을 수 있는 모든 음식, 머신러닝 = 고기 음식, 딥러닝 = 최고급 스테이크

강의 0:24“인공지능이나 머신러닝, 딥러닝 이런 것들 용어를 좀 혼동해서 쓰는 경우가 있는데” · 0:32“인공지능이 가장 큰 범위 그리고 그 안에 머신 러닝 그리고 이제 딥 러닝이 내포되어 있다”

딥러닝 실행 3요소

  • ① 데이터 ② 컴퓨터 ③ 프로그램
  • 3요소 중 가장 중요한 것 = 데이터. 방대한 양 + 질적으로 우수한 질이 필요. 컴퓨터·프로그램은 남들이 만들어 놓은 것을 가져다 쓸 수 있음
  • GPU = 고속 그래픽 처리에 특화된 전용 프로세서. 딥러닝 계산에 씀 (CPU보다 빠름, TPU는 구글 클라우드에서만 쓰는 하드웨어)
  • 프로그램 = 파이썬 + 텐서플로(구글이 만든 딥러닝 모듈) + 넘파이(행렬 계산을 쉽게 해 주는 모듈)

강의 23:21“제일 중요한 세 가지 요소. 첫 번째 데이터, 두 번째 뭐였나요? 컴퓨터 그다음에 세 번째 프로그램” · 24:36“그래서 데이터가 제일 중요하다”

지도 학습 · 비지도 학습

  • 라벨링 = 데이터에 이름표(답)를 붙이는 것 (이미지 A → 고양이, B → 강아지)
  • 지도 학습 = 문제와 답(이름표)을 함께 주고 그 이름표를 맞히게 하는 것. 교재 예제는 대부분 지도 학습
  • 비지도 학습 = 이름표 없이 특징만으로 학습. 지도 학습보다 난도가 높음 (생성형 AI가 일종의 비지도)
  • 학습 방법은 지도 학습과 비지도 학습 두 가지

몰라도 되는 것 구글 코랩 관련 내용 전부(코랩 문제는 출제하지 않음: 설치·런타임·드라이브 저장·텍스트 셀 등), CNN·RNN(“참고만 하시고”)

2장. 미지를 예측하는 원리와 첫 딥러닝 코드

정리본머신러닝과 일반 프로그래밍의 차이 · 신규 데이터 예측이 딥러닝 (이런 부분들 위주로) · 환경, 데이터 준비, 모델 실행까지 충분히 학습 · 데이터 구조 용어 · 텐서플로 기본 + 케라스, 층을 쌓아 고도화

딥러닝이 하는 일: 일반 프로그래밍 vs 머신러닝

구분넣는 것얻는 것초점
일반 프로그래밍데이터 + 규칙(코드)답데이터에서 답을 구함
머신러닝(딥러닝)데이터 + 답규칙(패턴)데이터와 답 사이의 규칙을 발견
  • 일반 프로그래밍은 답을 구하는 데, 머신러닝은 데이터와 답 사이의 규칙을 발견하는 데 초점
  • 찾아낸 규칙으로 처음 보는 신규 데이터의 답을 예측하는 것이 딥러닝이 하는 일
  • 학습 = 데이터가 입력되고 패턴이 분석되는 과정 / 모델 = 학습 결과로 만들어져 새 데이터를 예측하는 것
  • 예: 폐암 수술 환자 데이터로 학습 → 새 환자가 수술 1년 후 생존(1)인지 사망(0)인지 판정

딥러닝 4단계

  • 환경 준비 → 데이터 준비 → 구조 결정 → 모델 실행
단계하는 일
① 환경 준비모듈 불러오기 (텐서플로 2개 + 넘파이 1개, import numpy as np)
② 데이터 준비데이터를 불러와 속성 X와 클래스 y로 나눔. 불필요한 속성은 잘라냄(전처리)
③ 구조 결정Sequential로 모델 선언, Dense로 층을 쌓음
④ 모델 실행compile로 설정 → fit으로 학습

강의 26:32“중요하다고 언급됐던 몇 가지 구조만 익히시면 됩니다 … 큰 틀은 벗어나지 않습니다. 따라서 여기에 대한 내용을 꼭 숙지하시길 바랍니다”

딥러닝 데이터 구조 용어

  • 속성 = 입력 항목, 대문자 X / 클래스 = 결과(답), 소문자 y / 샘플 = 데이터 한 줄(환자 한 명)
  • 입력층 = 데이터가 처음 들어오는 층 / 은닉층 = 입력층과 출력층 사이의 층 / 출력층 = 최종 결과를 내보내는 층
  • 폐암 데이터: 환자 470명, 한 줄에 숫자 17개 = 속성 16개 + 클래스 1개(사망 0 / 생존 1) → X = 0~15번 열, y = 16번 열
  • 정확도 0.85 = 100명 중 15명은 오진할 수 있다는 뜻. 실행할 때마다 결과가 조금씩 다른 이유 = 처음 가중치를 랜덤으로 정하기 때문
  • 가중치 = 입력마다 다르게 주는 중요도(성향·취향). 처음엔 랜덤으로 정하고, 음식 간을 맞추듯 반복해서 고쳐 나감

강의 13:45“중요한 부분만 입력 결과 한 개. 요때는 보통 여기를 입력층이라 부르고요 … 여기는 출력층이라고 부릅니다”

텐서플로 · 케라스와 층 쌓기

  • 텐서플로를 기본으로 하고 케라스로 모델을 만듦. 텐서플로 = 구글의 딥러닝 전용 라이브러리(전투기), 케라스 = 텐서플로를 쉽게 쓰게 해 주는 도구(조종사)
  • 층을 쌓아 고도화: model.add(Dense(...))로 층을 계속 추가. 단, 은닉층이 두꺼울수록 좋을 수도 나쁠 수도 있음(휴지 비유, 출력이 안 나올 수 있음)
  • Sequential = “이제 구조 만들어요”라는 모델 선언 / Dense = 층 하나
  • compile = 만든 구조를 최적화하는 설정(loss = 손실(오차) 함수, optimizer = 최적화 함수) / fit = 실제 학습 (옷을 몸에 맞추듯)
  • epochs = 전체 데이터를 몇 번 반복할지(500쪽 책을 5번) / batch_size = 한 번에 학습하는 양(16쪽씩)

강의 14:15“fit이라고 불리는 거 중요한 거. 요거랑 배치 사이즈를 알아두시는게…”

model = Sequential()
model.add(Dense(30, input_dim=16, activation='relu'))   # 은닉층
model.add(Dense(1, activation='sigmoid'))                # 출력층
model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
model.fit(X, y, epochs=5, batch_size=16)
  • Dense가 2개이므로 층 2개(은닉층 1 + 출력층 1). input_dim=16 = 속성 16개를 첫 층에 넣음 → 풀이 ⑬

몰라도 되는 것 import 줄 세부(“딴 거 신경 쓸 필요 없으시고”), metrics(“보통 어큐러시”), loss·optimizer 종류의 자세한 내용(뒤 장에서 다시 나옴)

3장. 딥러닝을 위한 기초 수학

정리본기울기, 간단한 기본적인 최솟값 계산 그래프 관련 문제 내긴 낼 거라 알아두기 · 편미분이란 용어도 기억 · 시그모이드 함수도 꼭 기억

1차 함수: 기울기와 절편

  • y = ax + b에서 기울기 a = (y 증가량) ÷ (x 증가량). x가 1 늘 때 y가 a만큼 변함 → 풀이 ①
  • 절편 b = 그래프가 y축과 만나는 지점
  • 강의 예: x가 1 늘 때 y도 1 늘고, y축과 3에서 만남 → a = 1, b = 3 → y = x + 3
  • 딥러닝을 가장 간단하게 말하면 = x와 원하는 y가 있을 때 가장 알맞은 a와 b를 찾는 것

강의 26:29“제일 중요한 거는 … ax + b 1차 함수고요. 그다음에 2차 함수 … 기울기 요런 부분들 … 그다음에 시그모이드 함수를 알아두시길 바랍니다”

2차 함수와 최솟값

  • 2차 함수 그래프는 포물선, 맨 아래 꼭짓점이 최솟값 → 그래프·최솟값 계산 문제 → 풀이 ②
  • y = a(x − p)² + q → 꼭짓점 (p, q), 최솟값은 q
  • 최솟값을 찾는 과정이 중요한 이유: 모델이 잘됐는지 확인하는 기준(오차)이 2차 함수 모양이라, 최솟값 = 오차가 가장 작은 곳 → 4·5장

미분: 순간 변화율 = 기울기

  • 미분 = 한 점에서의 순간 변화율, 즉 그 점의 접선의 기울기를 구하는 것. “딥러닝에서 가장 중요한 수학 원리는 미분”
  • 최솟값(꼭짓점)에서는 기울기(미분값) = 0, 접선이 x축과 평행
  • 평균 변화율 = 두 점을 이은 직선의 기울기 Δy ÷ Δx. Δx를 0에 가깝게 줄이면 순간 변화율(미분)
  • 미분 공식 5가지: 상수 → 0 / x → 1 / ax → a / xⁿ → n·xⁿ⁻¹ / 합성함수 → 겉미분 × 속미분

강의 17:45“다섯 가지 미분 공식인데 … 시험 문제 내지는 않을 텐데 … 장담을 못 드리겠습니다. 그래도 한번은 봐 두시길 바랍니다”

편미분

  • 편미분 = 변수가 여러 개일 때 원하는 한 변수만 미분하고 나머지는 상수로 취급 (기호 ∂). 용어를 기억할 것
  • 계산보다 용어와 뜻이 중요. 5장 경사하강법에서 a와 b를 각각 편미분할 때 다시 나옴

강의 26:56“편미분 이런 거 할 줄 알아? 아니요. 지금 당장은 모르셔도 상관은 없습니다” → 계산 예시는 풀이 ③(참고)

지수 함수와 시그모이드 함수

  • 시그모이드 함수 f(x) = 1 / (1 + e⁻ˣ). S자 모양, 값은 항상 0~1. x가 크면 1에, 작으면 0에 가까워짐, x = 0이면 0.5 → 풀이 ④
  • 0 또는 1, 둘 중 하나를 고를 때 유용 (강아지인가 아닌가) → 6장 로지스틱 회귀
  • 활성화 함수 = 출력값으로 얼마나 내보낼지 계산하는 함수. 시그모이드는 가장 먼저 배우는 활성화 함수
  • 지수 함수 = 변수 x가 지수 자리에 있는 함수 (aˣ, a = 밑). 시그모이드의 밑 e = 자연상수 ≈ 2.7
  • 로그 함수 = 지수 함수를 뒤집은 모양. 6장 교차 엔트로피에서 씀
  • 딥러닝에 쓰는 기초 수학 7가지: 1차 함수, 2차 함수, 미분, 편미분, 지수, 시그모이드, 로그

4장. 선형회귀 · 최소제곱법 · 평균제곱오차

정리본선형회귀 최소제곱법 평균제곱오차 꼭 기억! · 선형회귀의 정의, 독립변수, 종속변수 꼭 기억 · 저 두 개 계산을 시킬 수도 있으니 그에 맞게 알아두어야 함

선형회귀와 독립변수 · 종속변수

  • 회귀 = ‘과거로 돌아가다’가 아니라 ‘예측하다’. 딥러닝의 두 기본 원리 = 선형 회귀 + 로지스틱 회귀(6장)
  • 선형회귀 = 독립변수 x로 종속변수 y를 예측하도록, 점들의 특징을 가장 잘 나타내는 직선을 긋는 것. 즉 오차가 가장 적은 최적의 a와 b를 찾는 작업
  • 독립변수 x = 결과에 영향을 주는 정보(공부 시간) / 종속변수 y = x에 의해 영향을 받는 결과(성적)
  • x가 하나면 단순 선형회귀, 두 개 이상이면 다중 선형회귀 → 5장에서 비교
  • 정보 = 성적은 [공부 시간 / 컨디션 / 사교육비]에 따라 다르다에서 괄호 안 내용. 머신러닝·딥러닝은 모두 이 정보가 필요함

최소제곱법

a = Σ(x − x̄)(y − ȳ) ÷ Σ(x − x̄)²   ·   b = ȳ − a·x̄
  • 최소제곱법 = 위 공식으로 기울기 a와 절편 b를 바로 구하는 방법. 분모는 x만 제곱, a를 먼저 구한 뒤 b
  • 강의 예제 (공부 시간 2, 4, 6, 8 / 성적 81, 93, 91, 97): x̄ = 5, ȳ = 90.5 → a = 2.3, b = 79 → y = 2.3x + 79 → 풀이 ⑤
  • 이 직선으로 7시간 공부한 학생을 예측하면 2.3 × 7 + 79 = 95.1점(약 95점)
  • 한계: 입력(독립변수)이 여러 개면 쓰기 어려움 (폐암 데이터는 독립변수 16개) → 오차를 조금씩 줄여 가는 경사하강법(5장)이 필요

오차와 평균제곱오차 (MSE)

MSE = (1/n) × Σ(실제값 − 예측값)²
  • 실제값 = 데이터에 있는 값 / 예측값 = 직선 식에 x를 넣어 구한 값 / 오차 = 실제값 − 예측값. 오차가 작을수록 모델 성능이 좋음
  • 평균제곱오차(MSE, Mean Squared Error) = 오차를 제곱해 모두 더한 뒤 개수 n으로 나눈 값. 직선을 평가하는 기준, 작을수록 좋음
  • MSE는 손실 함수(오차 함수)의 하나이며 오차를 구할 때 가장 많이 쓰는 방법. 제곱하는 이유 = +, − 오차가 서로 지워지지 않게
  • 강의 예: 임의로 그은 직선 y = 3x + 76 → 오차 제곱의 합 44 → MSE = 44 ÷ 4 = 11 → 풀이 ⑦
  • 딥러닝의 핵심 원리: 선을 긋고 → 오차를 계산하고 → 오차가 작아지는 쪽으로 고치고 → 반복
  • 기울기를 너무 크게 잡아도, 너무 작게 잡아도 오차가 커짐 → 5장 포물선 그래프

강의 18:32“각 선의 오차를 계산할 수 있어야 하고 오차가 작은 쪽으로 바꾸는 알고리즘이 필요하다라는 겁니다. 중요한 부분입니다”

참고 강의에서는 “일일이 다 계산하실 필요 없습니다”(22:30)라고 했지만, 정리본에서 “계산을 시킬 수도 있으니 알아두라”고 했으므로 최소제곱법·MSE 계산은 준비. 파이썬 최소제곱 코드는 “가볍게 살펴만”

5장. 경사하강법 · 단순 vs 다중 선형회귀

정리본경사하강법 잊어버리면 안 됩니다 · 선형회귀도 단순, 다중으로 분류되어서 두 차이점에 대해 정확하게 알아두기

경사하강법

  • 기울기 a와 오차의 관계 = 2차 함수(포물선). 꼭짓점 m에서 오차가 가장 작고, 그곳의 미분값은 0
  • 경사하강법 = 오차의 변화를 2차 함수 그래프로 보고, 적절한 학습률을 정해서 미분값이 0인 지점(오차가 최소인 m)을 찾는 방법
  • 움직이는 방법: 미분값(기울기)의 반대 방향으로 a₁ → a₂ → a₃ … 조금씩 옮겨 m으로 내려감(그래서 ‘하강’) → 풀이 ⑨
  • 학습률 = 한 번에 이동하는 거리(보폭). 너무 크면 튕겨 나가 발산, 적절하면 한 점으로 모이는 수렴. 최적의 학습률을 찾는 것도 중요한 최적화 과정
  • a와 b를 둘 다 찾아야 하므로 a와 b로 각각 편미분 (“편미분도 중요한 포인트니까 … 용어만 알고 계시면 됩니다”)
  • MSE + 경사하강법을 쓰면 최소제곱법 없이도 최적의 a, b를 찾을 수 있음 (독립변수가 많아도 가능)
  • 강의 실습: a = 0, b = 0에서 시작, 학습률 0.03, 2000번 반복 → a = 2.3, b = 79 (최소제곱법과 같은 결과)

강의 10:06“경사하강법은 오차의 변화에 따라서 2차 함수 그래프를 만들고 적절한 학습률을 설정해서 미분값이 0인 지점을 구하는 것이다”

하이퍼파라미터

  • 하이퍼파라미터 = 사용자가 임의로 정할 수 있는 값. 케라스에서 조정하는 4가지 = activation, optimizer, loss, epochs
  • 에포크(epoch) = 전체 데이터로 몇 번 반복해서 학습했는지
  • epochs가 크다고 정답은 아님: 1900번째에 이미 2.3과 79가 나왔으므로 거기서 끊는 게 나을 수 있음

6장. 로지스틱 회귀

정리본로지스틱 회귀가 뭔지 개념 및 용어 익숙해져야 하고 · 어떤 함수 쓰이고 왜 쓰이는지 · 시그모이드 함수에 이어서 오차 기억 · 옵티마이즈 할 때 로지스틱 회귀 용어 꼭 기억

로지스틱 회귀와 시그모이드

  • 로지스틱 회귀 = 참/거짓(예/아니오, 합격/불합격)을 판단하는 예측 모델. 직선 대신 S자 곡선으로 참과 거짓을 나눔
  • 쓰는 함수 = 시그모이드 함수 / 쓰는 이유 = 결과가 0 또는 1뿐이라(사이 값이 없음) 직선으로 표현하기 어려움 → S자 모양으로 0~1 사이 값을 냄
  • 식: y = 1 / (1 + e−(ax + b)). 핵심은 가운데의 ax + b
  • a = 경사도: 작으면 완만, 크면 거의 수직으로 가파름(“형태만 기억”) / b = 그래프를 좌우로 이동
  • a가 너무 작아지면 오차가 무한대로 커지고, b가 너무 크거나 작아도 오차가 커짐 → a, b는 경사하강법으로 구함

강의 7:06“로지스틱 회귀는 뭘 쓴다? 시그모이드 함수를 쓴다. 왜? S자이기 때문에요. 세 가지만 기억을 하셔도 상관없습니다”

오차: 교차 엔트로피

  • 로지스틱 회귀의 오차(손실 함수) = 교차 엔트로피(크로스 엔트로피). MSE를 못 쓰는 이유 = 시그모이드 출력이 0~1 사이라서
  • 선형 회귀 = 평균제곱오차, 로지스틱 회귀 = 교차 엔트로피 (“지금은 두 개만 기억하셔도 됩니다”)
  • 로그 함수를 씀: 실제값이 1인데 예측이 0에 가까우면 오차가 커짐(−log h), 실제값이 0인데 예측이 1에 가까우면 오차가 커짐(−log(1 − h)). 합친 식 = −{y·log h + (1 − y)·log(1 − h)}
  • binary_crossentropy = 이진(OX) 분류용 교차 엔트로피. 고양이·개·사자처럼 3개 이상이면 다른 것을 씀(나중에)

강의 11:44“교차 엔트로피도 알아두시고 … 선형 회귀는 평균제곱오차, 로지스틱 회귀는 교차 엔트로피 … 지금은 두 개만 기억하셔도 됩니다”

7장. 퍼셉트론

정리본퍼셉트론이 무엇인지 · 기본적인 합성곱, 다중합 알아두기 → 강의에서 설명한 가중합을 말함

퍼셉트론이란

  • 퍼셉트론 = 입력값을 여러 개 받아 출력을 만드는데, 입력값에 가중치를 조절할 수 있게 해서 최초로 학습을 하게 한 것. 뇌의 뉴런을 본뜬 인공 신경망의 가장 작은 시작
  • 신경망(뉴럴 네트워크) = 인간 뇌의 뉴런과 시냅스 연결을 모방한 구조
  • 뇌의 뉴런은 약 1천억 개. 신호가 임계값을 넘으면 다음 뉴런으로 전달하고, 못 넘으면 아무것도 하지 않음
  • 역사: 1943년 논문(신경을 그물망처럼 연결하면 뇌처럼 동작할 수 있다고 처음 주장) → 퍼셉트론 → 3년 후 아달라인 → SVM, 로지스틱 회귀
  • 아달라인 = 퍼셉트론에 경사하강법을 도입해 오차가 최소인 여러 직선 중 가장 적절한 경계선을 고르게 한 것. 이 중 시그모이드를 활성화 함수로 쓴 것이 로지스틱 회귀

강의 5:00“그것이 이제 퍼셉트론이라는 거더라. 이거는 뭐 당연히 시험이 나오겠죠. 알아두시면 좋고”

가중합 (정리본의 ‘합성곱 · 다중합’)

가중합 y = x₁w₁ + x₂w₂ + b
  • 가중합 = 입력과 가중치를 모두 곱한 뒤 바이어스를 더한 것 (곱하고, 더하고, 곱하고, 마지막에 b) → 풀이 ⑩
  • 가중치 w = 입력마다 곱하는 중요도 / 바이어스(편향) b = 마지막에 더하는 값 (5장 용어와 같음)
  • 다중 선형회귀 식(y = a₁x₁ + a₂x₂ + b)과 같은 꼴. 입력이 100개, 1000개여도 xₙwₙ까지 똑같이 늘어남
  • 구조: 가중합 → 활성화 함수(내보낼지 말지 예스/노 판단) → 출력. 활성화 함수로 시그모이드를 쓰면 로지스틱 회귀

강의 7:45“로지스틱 회귀 모델은 여기에 시그모이드 함수를 활용해서 … 참 거짓을 판단, 이게 활성 함수죠 … 요 구조까지만 일단은 기억을 해 두세요” · 7:58“가중합이란 입력과 가중치를 모두 곱한 후에 바이어스를 더했다”

‘다중합’이라는 말은 강의에 없고, ‘합성곱’은 8장에서 가중합을 가리키는 말로만 썼습니다(CNN의 합성곱이 아님). 시험에서 ‘합성곱·다중합’으로 나와도 가중합으로 답하면 됩니다.

퍼셉트론의 한계: XOR 문제

  • 게이트 = 0과 1을 넣어 하나의 값을 내는 회로. AND = 둘 다 1일 때만 1 / OR = 하나라도 1이면 1 / XOR = 서로 다를 때만 1
  • AND·OR은 직선 하나로 나눌 수 있지만 XOR은 직선 하나로 나눌 수 없음 (퍼셉트론·아달라인은 2차원 평면에서 직선만 그을 수 있음)
  • ‘퍼셉트론즈’ 논문이 XOR도 못 푼다는 한계를 지적 → 인공지능 침체기 → 해결: 다층 퍼셉트론 + 오차 역전파(8장)

8장. 다층 퍼셉트론

정리본다층 퍼셉트론이 왜 나왔는지 기억할 것

다층 퍼셉트론이 나온 이유

  • 단일 퍼셉트론으로 AND·OR은 풀 수 있지만 XOR 문제를 풀 수 없어서, 여러 개의 퍼셉트론을 이용해 해결하려고 고안한 것
  • 핵심 발상: 종이를 휘어 선 두 개를 동시에 긋기 = 퍼셉트론 두 개를 한 번에 계산
  • 성냥개비 6개로 정삼각형 4개: 평면에서는 불가능, 3차원(피라미드)이면 가능 → 차원을 바꿔 생각
  • 은닉층 = 입력층과 출력층 사이에서 퍼셉트론 두 개를 각각 처리하는 층 / 노드 = 은닉층의 중간 정거장(n₁, n₂ …)

강의 0:31“단일 퍼셉트론으로는 … AND OR은 해결할 수 있었지만 XOR 문제를 해결할 수가 없었기 때문에 이것을 다수의 퍼셉트론을 이용해서 해결하고자 고안된 것이다”

XOR을 푸는 구조

  • 은닉층에서 NAND와 OR을 계산하고, 그 결과를 AND로 합치면 XOR과 같은 결과 → 풀이 ⑪
  • NAND = AND의 부정 (AND 결과를 뒤집은 것)
  • 은닉층 가중합: n₁ = x₁w₁₁ + x₂w₂₁ + b₁, n₂ = x₁w₁₂ + x₂w₂₂ + b₂ → 출력 y = n₁w₃₁ + n₂w₃₂ + b₃ → 활성화 함수 (같은 퍼셉트론 연산을 한 번 더)
  • 입력 2 · 은닉 노드 2 · 출력 1 → 가중치 6개, 바이어스 3개 → 풀이 ⑫
  • 가중치는 기하급수적으로 늘어남 (입력 100개 × 노드 100개 = 최소 1만 개). 은닉층을 여러 겹 두껍게 쌓으면 복잡한 신경망 → 2장 ‘층 쌓기’

강의 9:22“중요한 부분 … 입력과 이럴 때 출력은 요렇게 나온다는 거 확인할 수 있죠 … XOR 게이트와 동일한 결과값”

남은 문제와 오차 역전파

  • 다층 퍼셉트론만으로 완전히 해결된 건 아님: 은닉층의 가중치를 데이터로 학습하는 방법이 아직 없었음
  • 인공지능의 겨울 = 이론은 나왔지만 그 뒤로 약 20년간 정체된 기간 (“이런 용어는 좀 알아두시면 좋을 거 같고요”)
  • 연구가 두 그룹으로 나뉨: ① 아달라인 → SVM·로지스틱 회귀 ② 다층 퍼셉트론의 학습 방법 연구
  • 오차 역전파 = 입력·노드·출력 사이의 가중치들을 업데이트할 수 있게 한 알고리즘
  • 제프리 힌튼 = ‘딥러닝의 아버지’. 오차 역전파, 활성화 함수, 가중치 설정 등으로 딥러닝에 크게 기여

풀이 ① 두 점을 지나는 직선 Q15

문제: (1, 4), (3, 10)을 지나는 직선의 식

  1. 기울기 a = (y 증가량) ÷ (x 증가량) = (10 − 4) ÷ (3 − 1) = 6 ÷ 2 = 3
  2. 한 점을 대입해 b 구하기: 4 = 3 × 1 + b → b = 1
  3. 답: y = 3x + 1 (검산: x = 3 → 9 + 1 = 10 ✓)

연습 (2, 5), (4, 9) → a = 4 ÷ 2 = 2, 5 = 4 + b → b = 1 → y = 2x + 1

풀이 ② 2차함수의 최솟값 Q17, Q18

방법 A (꼭짓점 꼴): y = (x − 3)² + 2 → 괄호 안이 0일 때 가장 작음 → x = 3, 최솟값 2

방법 B (미분 = 0): y = x² − 6x + 10

  1. 미분: y′ = 2x − 6 (x² → 2x, −6x → −6, 10 → 0)
  2. 미분값 = 0: 2x − 6 = 0 → x = 3
  3. 대입: y = 9 − 18 + 10 = 1 → 최솟값 1

연습 y = x² − 4x + 5 → y′ = 2x − 4 = 0 → x = 2 → y = 4 − 8 + 5 = 1

풀이 ③ 편미분 Q21

강의 예: f(x, y) = x² + xy

  1. x로 편미분: y는 숫자로 봄 → x² → 2x, xy → y → ∂f/∂x = 2x + y
  2. y로 편미분: x는 숫자로 봄 → x² → 0, xy → x → ∂f/∂y = x

연습 f(x, y) = x² + 3xy 를 x로 편미분 → 2x + 3y

풀이 ④ 시그모이드 값 Q23

f(0) = 1 / (1 + e⁰) = 1 / (1 + 1) = 0.5 (어떤 수든 0제곱은 1)

x가 매우 크면 e⁻ˣ → 0 이라 f → 1 / x가 매우 작으면 e⁻ˣ → 매우 큼 이라 f → 0

풀이 ⑨ 경사하강법 이동 방향 Q34
