1장. 딥러닝 준비

★ AI · 머신러닝 · 딥러닝의 포함 관계

  • ★ 인공지능(AI) ⊃ 머신러닝 ⊃ 딥러닝 (가장 큰 범주가 AI)
  • 인공지능: 사람처럼 판단하는 기계
  • 머신러닝: 데이터로 규칙을 찾아 예측. 데이터를 어떻게 쓸지는 사람이 정함
  • 딥러닝: 머신러닝 중 가장 고도화된 방식. 사람이 하던 수작업까지 학습으로 처리

★ 딥러닝 실행 3요소

  • ★ ① 데이터 ② 컴퓨터(CPU/GPU) ③ 프로그램(파이썬 + 텐서플로 + 넘파이)
  • 3요소 중 가장 중요한 것 = 데이터 (양이 많고 질이 좋아야 함. 컴퓨터·프로그램은 만들어진 것을 가져다 씀)

2장. 딥러닝이 하는 일, 코드 단계, 데이터 구조

★ 일반 프로그래밍 vs 머신러닝

구분입력출력
일반 프로그래밍데이터 + 규칙(코드)답
머신러닝(딥러닝)데이터 + 답규칙(패턴)
  • ★ 찾아낸 규칙으로 처음 보는 신규 데이터의 답을 예측하는 것이 딥러닝이 하는 일
  • 예: 폐암 수술 환자 속성 16개 → 수술 1년 후 생존(1) / 사망(0) 예측
  • 학습 = 데이터가 들어가 패턴이 분석되는 과정 / 모델 = 그 결과 만들어져 새 데이터를 예측하는 것

★ 코드 4단계

  • ★ 환경 준비 → 데이터 준비(X, y 분리) → 구조 결정(층 쌓기, 가장 핵심) → 모델 실행(compile → fit)

데이터 구조 용어

  • 속성(attribute) = 입력, 대문자 X / 클래스(class) = 결과, 소문자 y / 샘플 = 한 줄(환자 한 명)
  • 입력층 = 데이터가 처음 들어옴 / 은닉층 = 입력층과 출력층 사이 / 출력층 = 최종 결과를 내보냄

텐서플로 · 케라스와 층 쌓기

  • 텐서플로 = 전투기, 케라스 = 조종사 (케라스는 텐서플로를 쉽게 쓰게 해주는 도구)
  • Sequential = 모델을 만들겠다는 선언 / Dense = 층 하나
  • ★ 고도화: model.add(Dense(...))로 층을 계속 쌓아 나감. 단, 층이 너무 두꺼우면(휴지 비유) 학습이 잘 안 될 수 있음
  • compile = loss(손실 함수)·optimizer(옵티마이저) 등 설정 / fit = 실제 학습
  • epochs = 전체 데이터 반복 횟수(책 5번 정독) / batch_size = 한 번에 학습하는 양(16쪽씩)

코드 예시 (폐암 환자 데이터)

model = Sequential()
model.add(Dense(30, input_dim=16, activation='relu'))   # 은닉층
model.add(Dense(1, activation='sigmoid'))                # 출력층
model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
model.fit(X, y, epochs=5, batch_size=16)

→ Dense가 2개이므로 층 2개(은닉층 1 + 출력층 1). input_dim=16 = 입력값 16개를 첫 층에 전달 → 풀이 ⑬

3장. 기초 수학

기울기 · 절편 · 최솟값

  • 딥러닝 = 원하는 y를 얻는 가장 좋은 a(기울기), b(절편)를 찾는 일
  • 1차함수 y = ax + b : a = (y 증가량) ÷ (x 증가량), b = y절편(y축과 만나는 점) → 풀이 ①
  • 2차함수는 포물선, 꼭짓점 = 최솟값. 꼭짓점에서 미분값(접선의 기울기) = 0 → 풀이 ②
  • 미분 공식: 상수 → 0 / x → 1 / ax → a / xⁿ → n·xⁿ⁻¹ / 합성함수 → 연쇄적으로 곱함

★ 편미분

  • ★ 변수가 여러 개일 때 한 변수만 미분하고 나머지는 상수로 취급 (기호 ∂) → 풀이 ③

★ 시그모이드 함수

  • ★ f(x) = 1 / (1 + e⁻ˣ), S자 곡선, 출력은 항상 0~1, x = 0이면 0.5 → 풀이 ④
  • x가 클수록 1에, 작을수록 0에 가까워짐. 활성화 함수의 하나로 예/아니오 판단에 씀 → 6장

4장. 선형회귀 · 최소제곱법 · 평균제곱오차

★ 선형회귀와 독립·종속변수

  • ★ 선형회귀: 독립변수 x로 종속변수 y를 예측하는, 데이터에 가장 잘 맞는 직선(y = ax + b)을 찾는 방법
  • ★ 독립변수 x = 원인이 되는 정보(공부 시간) / 종속변수 y = x의 영향을 받는 결과(성적)
  • 독립변수 1개 = 단순 선형회귀, 2개 이상 = 다중 선형회귀

★ 최소제곱법

  • ★ a = Σ(x − x̄)(y − ȳ) ÷ Σ(x − x̄)², b = ȳ − a·x̄
  • 직선을 구하는 방법. 분모는 x만 제곱, a를 먼저 구한 뒤 b → 풀이 ⑤, 풀이 ⑥

★ 평균제곱오차 (MSE)

  • ★ MSE = (1/n) × Σ(실제값 − 예측값)²
  • 직선을 평가하는 방법, 작을수록 좋음 → 풀이 ⑦, 풀이 ⑧
  • 제곱하는 이유: 오차의 +, −가 서로 상쇄되지 않게 / 마지막에 n으로 나누는 것 잊지 말기

5장. 경사하강법 · 단순 vs 다중 선형회귀

★ 경사하강법

  • ★ 오차를 미분해서 기울기의 반대 방향으로 조금씩 이동하며, 미분값이 0인(오차가 최소인) 지점 m을 찾는 방법
  • 기울기 a와 오차의 관계 = 2차함수(포물선). 찾는 곳 = 꼭짓점(미분값 0)
  • 미분값 > 0 → a를 작게(왼쪽) / 미분값 < 0 → a를 크게(오른쪽). 왔다 갔다 하며 m에 수렴 → 풀이 ⑨
  • a와 b를 동시에 찾으므로 각각 편미분해서 업데이트: a ← a − 학습률 × ∂오차/∂a
  • 왜 필요? 최소제곱법은 변수가 많아지면 쓰기 어려움 → 반복해서 오차를 줄이는 방식

학습률 · 하이퍼파라미터

  • 학습률 = 한 번에 이동하는 보폭. 너무 크면 튕겨 나가 발산 / 너무 작으면 너무 느림
  • 하이퍼파라미터 = epochs, 학습률처럼 사용자가 직접 정하는 값

★ 단순 vs 다중 선형회귀

구분단순 선형회귀다중 선형회귀
독립변수1개2개 이상
식y = ax + by = a₁x₁ + a₂x₂ + b
그래프직선평면
예공부 시간 → 성적공부 시간 + 과외 횟수 → 성적
케라스input_dim=1input_dim=2 (출력은 여전히 1개)
  • ★ 변수가 많다고 항상 좋은 건 아님 → 결과와 연관성이 큰 변수를 골라야 함
  • 용어 대응: 기울기 = 가중치(w) / 절편 = 편향(bias) / 평균제곱오차 = 손실 함수(loss) / 경사하강법 = 옵티마이저
  • 선형회귀 코드: activation='linear', optimizer='sgd'(경사하강법), loss='mse'

6장. 로지스틱 회귀

★ 로지스틱 회귀와 시그모이드

  • ★ 로지스틱 회귀: 참/거짓(1/0) 중 하나를 판단하는 예측 모델. 시그모이드 함수를 씀
  • ★ 시그모이드를 쓰는 이유: 결과가 0 또는 1이라 직선으로 표현할 수 없음. 시그모이드는 S자로 0~1 사이 값을 냄(확률처럼 해석)
  • 식: y = 1 / (1 + e^−(ax + b)) → a = 경사도(크면 가파름), b = 좌우 이동
  • 선형회귀 = 수치 예측(성적 몇 점) / 로지스틱 회귀 = 참·거짓 분류(합격 여부)

★ 오차: 교차 엔트로피

  • ★ 오차 = 교차 엔트로피. MSE를 안 쓰는 이유: 출력이 0~1이라 맞지 않음, 로그를 써서 정답에서 멀어질수록 오차가 급격히 커지게 함
  • 식(보충): 오차 = −{ y·log h + (1 − y)·log(1 − h) } (실제 1이면 −log h, 실제 0이면 −log(1 − h))

7장. 퍼셉트론

★ 퍼셉트론과 가중합

  • 퍼셉트론: 뇌의 뉴런을 본떠 만든 인공 신경의 기본 단위. 여러 개가 모이면 신경망
  • ★ 가중합 = x₁w₁ + x₂w₂ + b → 활성화 함수에 넣어 출력 → 풀이 ⑩
  • 가중치 w = 입력의 중요도(선형회귀의 기울기) / 바이어스 b = 선형회귀의 절편
  • 활성화 함수 = 가중합을 보고 다음으로 내보낼지 정하는 관문 (계단 함수, 시그모이드, ReLU)
  • 강의에서 말한 '합성곱'은 7장 범위에서는 가중합(곱해서 더하기)으로 보면 됨

AND · OR · XOR

  • AND, OR은 직선 하나로 나눌 수 있음 → 퍼셉트론 하나로 가능 / XOR은 불가능 → 8장

8장. 다층 퍼셉트론

★ 다층 퍼셉트론이 나온 이유

  • ★ 단일 퍼셉트론으로 XOR 문제를 풀 수 없어서
  • XOR은 1인 점과 0인 점이 대각선으로 엇갈려 있어 직선 하나로 나눌 수 없음
  • 핵심 아이디어: 입력층과 출력층 사이에 은닉층을 만들어 퍼셉트론 두 개를 동시에 계산 (종이를 휘어 선 두 개를 긋는 것)
  • 은닉층에서 NAND와 OR을 계산하고, 그 결과를 AND로 합치면 XOR이 됨 → 풀이 ⑪
  • 층을 쌓을수록 더 복잡한 문제를 풀 수 있음 → 딥러닝의 기본 구조 (2장 '층 쌓기'와 연결)
  • 가중치 = 선(연결) 수, 바이어스 = 입력층을 뺀 노드 수 → 풀이 ⑫
  • 남은 문제: 은닉층 가중치를 어떻게 학습하나 → 오차 역전파(힌튼)로 해결

계산 문제 풀이

시험에서는 숫자만 바꿔 나올 수 있음. 순서를 외워 두고 연습 문제로 한 번씩 직접 풀어 볼 것. 번호(Q17 등)는 문제 메뉴의 예상 문제 번호.

풀이 ① 두 점을 지나는 직선 Q17

문제: (1, 4), (3, 10)을 지나는 직선의 식

  1. 기울기 a = (y 증가량) ÷ (x 증가량) = (10 − 4) ÷ (3 − 1) = 6 ÷ 2 = 3
  2. 한 점을 대입해 b 구하기: 4 = 3 × 1 + b → b = 1
  3. 답: y = 3x + 1 (검산: x = 3 → 9 + 1 = 10 ✓)

연습 (2, 5), (4, 9) → a = 4 ÷ 2 = 2, 5 = 4 + b → b = 1 → y = 2x + 1

풀이 ② 2차함수의 최솟값 Q19, Q20

방법 A (완전제곱식 꼴): y = (x − 3)² + 2 → 괄호 안이 0일 때 가장 작음 → x = 3, 최솟값 2

방법 B (미분 = 0): y = x² − 6x + 10

  1. 미분: y′ = 2x − 6 (x² → 2x, −6x → −6, 10 → 0)
  2. 미분값 = 0: 2x − 6 = 0 → x = 3
  3. 대입: y = 9 − 18 + 10 = 1 → 최솟값 1

연습 y = x² − 4x + 5 → y′ = 2x − 4 = 0 → x = 2 → y = 4 − 8 + 5 = 1

풀이 ③ 편미분 Q23

문제: f(x, y) = x² + 3xy 를 x에 대해 편미분

  1. y는 숫자(상수)로 본다 → 3xy는 ‘3y × x’ 꼴
  2. x² → 2x, 3y·x → 3y
  3. 답: ∂f/∂x = 2x + 3y

참고: y로 편미분하면 x²는 상수 → 0, 3x·y → 3x → ∂f/∂y = 3x

풀이 ④ 시그모이드 값 Q25

f(0) = 1 / (1 + e⁰) = 1 / (1 + 1) = 0.5 (어떤 수든 0제곱은 1)

x가 매우 크면 e⁻ˣ → 0 이라 f → 1 / x가 매우 작으면 e⁻ˣ → 매우 큼 이라 f → 0

풀이 ⑧ 평균제곱오차 (작은 숫자) Q33

  1. 예측값: 2, 4, 6
  2. 오차: 3 − 2 = 1, 5 − 4 = 1, 7 − 6 = 1
  3. 제곱의 합: 1 + 1 + 1 = 3
  4. MSE = 3 ÷ 3 = 1

풀이 ⑨ 경사하강법 이동 방향 Q36 이해용 예시

풀이 ⑩ 퍼셉트론 가중합 Q50

  1. 가중합 = x₁w₁ + x₂w₂ + b = 1 × 0.6 + 0 × 0.4 + (−0.5) = 0.1
